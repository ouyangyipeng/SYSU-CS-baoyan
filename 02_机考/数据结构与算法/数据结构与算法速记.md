# 数据结构与算法

用于复习基础概念与口头简答。S 为优先掌握，A 为常见知识，B 为扩展内容；标记表示复习建议，不是出题概率统计。

## 复杂度

### [S] O、Ω、Θ

- $O$：渐进上界；$\Omega$：渐进下界；$\Theta$：同阶紧确界。
- 最坏、平均、摊还复杂度是不同维度，不要混用。

## 排序

### [S] 快速排序

- 平均 $O(n\log n)$，最坏 $O(n^2)$；原地版本额外栈平均 $O(\log n)$。
- 通常不稳定。随机 pivot 或三数取中减少极端退化。

### [S] 归并排序

- 时间始终 $O(n\log n)$，额外空间 $O(n)$，稳定。
- 适合外部排序和链表排序。

### [A] 堆排序

- 时间 $O(n\log n)$，额外空间 $O(1)$，不稳定。
- 建堆可 $O(n)$，不是 $O(n\log n)$。

### [A] 希尔排序

- 分组插入排序，复杂度依赖 gap 序列；通常不稳定。
- 与快排相比，快排平均 $O(n\log n)$ 且工程常数好；希尔排序理论界与 gap 相关。

## 树

### [S] B 树与 B+ 树

- 都是多路平衡搜索树，减少磁盘 I/O。
- B+ 树数据通常只存叶子；内部节点仅索引；叶子有序链表，范围查询高效。
- 数据库索引常用 B+ 树，因为扇出大、树矮、范围扫描方便。

### [S] 哈夫曼树

- 给定权重，带权路径长度最小的二叉树。
- 每次合并权重最小的两个节点，使用优先队列；用于前缀编码。

### [A] BST、AVL、红黑树

- BST 平均查找 $O(\log n)$，最坏退化 $O(n)$。
- AVL 平衡更严格，查询快但旋转多。
- 红黑树平衡稍松，插入删除性能稳定，标准库 `map/set` 常用。

### [A] Trie

- 按字符边组织前缀；查询 $O(L)$，空间可能大。

## 哈希表

### [S] 原理与冲突

- 哈希函数把 key 映射到桶；平均查找/插入 $O(1)$，最坏 $O(n)$。
- 冲突处理：链地址法、开放寻址。
- 负载因子过高会增加冲突，需要 rehash。

## 图算法

### [S] BFS 与 DFS

- BFS 用队列，适合无权图最短路；DFS 用栈/递归，适合连通、环、拓扑等。
- 邻接表复杂度均为 $O(V+E)$。

### [S] 最短路

- Dijkstra：非负边权；堆优化约 $O((V+E)\log V)$。
- Bellman–Ford：允许负边，可检测负环，$O(VE)$。
- Floyd–Warshall：全源最短路，$O(V^3)$。

### [S] 最小生成树

- Kruskal：按边权排序 + 并查集，适合稀疏图。
- Prim：逐步扩展顶点集合，堆优化适合一般图。
- MST针对连通无向带权图；最短路树与 MST 目标不同。

### [A] 拓扑排序

- 只适用于 DAG；Kahn 算法不断删除入度 0 节点。
- 无法处理完所有顶点说明存在环。

### [A] 并查集

- 管理不相交集合；路径压缩 + 按秩合并，均摊近似 $O(1)$。

## 动态规划与贪心

### [S] 动态规划

- 适合最优子结构 + 重叠子问题。
- 四步：状态、转移、初值、遍历顺序；最后再考虑空间优化。

### [S] 贪心

- 每步做局部最优选择；必须证明贪心选择性质和最优子结构。
- 并非所有 DP 都能改成贪心。
