### 第一题：深拷贝 【补全代码，类与对象】

 

描述

 

在C++中，当类包含指向动态分配内存的指针成员时，默认的拷贝构造函数和赋值运算符只会进行“浅拷贝”，这会导致多个对象指向同一块内存，在析构时引发内存泄漏或重复释放的错误。

 

现提供一个 String 类的框架，内部包含一个 char\* 类型的指针 data。请补全代码，实现 String 类的拷贝构造函数和赋值运算符（operator=），确保进行深拷贝。

 

请勿提交 main 函数。

 

输入/输出

 

根据补全的代码，系统将自动测试创建对象、拷贝对象以及对象赋值后的内存地址独立性和内容一致性。

 

核心原理： 默认的浅拷贝只是把指针的地址复制了一份，导致两个对象共享同一块内存，这在析构时会引发“Double Free”（重复释放内存）的致命崩溃。 深拷贝的核心在于：重新开辟一块独立内存，并将原内存中的数据复制过来。另外，在写赋值运算符 operator= 时，一定要记得先判断是不是“自己给自己赋值”，并释放原有内存。

 

参考代码：

```cpp
#include <cstring>
#include <iostream>


class String {
private:
    char* data;


public:
    // 默认构造函数
    String(const char* str = nullptr) {
        if (str) {
            data = new char[strlen(str) + 1];
            strcpy(data, str);
        } else {
            data = new char[1];
            *data = '\0';
        }
    }


    // 1. 拷贝构造函数 (Deep Copy Constructor)
    String(const String& other) {
        // 重新分配内存并拷贝内容
        data = new char[strlen(other.data) + 1];
        strcpy(data, other.data);
    }


    // 2. 赋值运算符 (Assignment Operator)
    String& operator=(const String& other) {
        // 避免自我赋值 (如 str1 = str1;)
        if (this != &other) { 
            // 释放原有的内存，防止内存泄漏
            delete[] data;    
            
            // 重新分配内存并拷贝内容
            data = new char[strlen(other.data) + 1];
            strcpy(data, other.data);
        }
        return *this; // 支持连续赋值 (如 a = b = c)
    }


    // 析构函数
    ~String() {
        delete[] data;
    }
};
```

### 第二题：继承与多态 【补全代码，虚继承，虚函数】

 

描述

 

本题考查C++面向对象中的菱形继承问题。

 

已知有基类 Base，以及派生类 Derived1 和 Derived2，最后有一个类 Final 同时继承自 Derived1 和 Derived2。

 

请补全类的声明和实现代码：

 
1. 确保 Final 类在实例化时，Base 类只被构造一次（使用虚继承）。
 
2. 在 Base 中声明虚析构函数，以确保通过基类指针释放 Final 对象时，能正确调用所有派生类的析构函数。
 
3. 补全对应的多态打印函数。
 

请勿提交 main 函数。

 

核心原理： 菱形继承中，底部的类会包含两份最顶层基类的实例。通过在派生时加上 virtual 关键字，可以保证最顶层基类在内存中只存在一份。同时，带有虚函数的基类，其析构函数必须声明为虚函数（virtual ~Base()），否则通过基类指针 delete 派生类对象时，派生类的析构函数不会被执行，造成内存泄漏。

```cpp
#include <iostream>


class Base {
public:
    Base() { std::cout << "Base Constructor\n"; }
    
    // 1. 虚析构函数：确保多态下资源正确释放
    virtual ~Base() { std::cout << "Base Destructor\n"; }
    
    virtual void print() const { std::cout << "Base\n"; }
};


// 2. 虚继承：解决菱形继承的数据冗余和二义性
class Derived1 : virtual public Base {
public:
    Derived1() { std::cout << "Derived1 Constructor\n"; }
    ~Derived1() override { std::cout << "Derived1 Destructor\n"; }
    void print() const override { std::cout << "Derived1\n"; }
};


// 2. 虚继承
class Derived2 : virtual public Base {
public:
    Derived2() { std::cout << "Derived2 Constructor\n"; }
    ~Derived2() override { std::cout << "Derived2 Destructor\n"; }
    void print() const override { std::cout << "Derived2\n"; }
};


// 3. 多继承派生类
class Final : public Derived1, public Derived2 {
public:
    Final() { std::cout << "Final Constructor\n"; }
    ~Final() override { std::cout << "Final Destructor\n"; }
    void print() const override { std::cout << "Final\n"; }
};
```

### 第三题：挖矿问题 【补全代码，DFS，链表】

 

描述

 

给定一个

N×M

的二维网格数组，代表一个矿区，网格中的每个数字代表该坐标的矿石价值。

 

你需要实现一个简单的二维网格深度优先搜索（DFS）来“挖矿”。对于值大于设定阈值 threshold 的网格，将其坐标及价值作为一个节点插入到一个按价值升序排列的链表中，并在访问后将原二维数组中的该点价值修改为0。

 

最后，你需要实现一个链表的删除函数 deleteNode，用于从该链表中安全地删除指定价值的节点。

 

请勿提交 main 函数。

 

输入/输出

 

系统将传入二维数组及阈值，并测试链表的升序排列情况以及删除函数是否正确处理了头结点、尾结点和中间节点的删除。

 

核心原理： 这题是图论搜索和链表操作的结合体。DFS 搜索网格时，遇到价值大于 threshold 的就调用“有序链表插入函数”。删除链表节点时，使用虚拟头节点（Dummy Node）技巧，可以统一处理删除头结点和中间结点的逻辑，避免满屏的 if-else。

 

参考代码：

```cpp
struct ListNode {
    int val;
    int r, c; // 记录坐标
    ListNode* next;
    ListNode(int v, int row, int col) : val(v), r(row), c(col), next(nullptr) {}
};


int threshold = 5;
int R, C;
vector<vector<int>> grid;
ListNode* head = nullptr;


// 有序插入链表（升序）
void insertSorted(int val, int r, int c) {
    ListNode* newNode = new ListNode(val, r, c);
    // 如果链表为空，或者新节点的值比头节点小，插在头部
    if (!head || head->val >= val) {
        newNode->next = head;
        head = newNode;
        return;
    }
    // 找到第一个比它大的节点的前驱
    ListNode* curr = head;
    while (curr->next && curr->next->val < val) {
        curr = curr->next;
    }
    newNode->next = curr->next;
    curr->next = newNode;
}


// DFS 挖矿搜索
void dfs(int r, int c) {
    // 越界或已经挖过/没矿 (设0为无矿)
    if (r < 0 || r >= R || c < 0 || c >= C || grid[r][c] == 0) return;
    
    int val = grid[r][c];
    grid[r][c] = 0; // 挖走，标记为0
    
    if (val > threshold) {
        insertSorted(val, r, c);
    }
    
    // 搜索四个方向
    dfs(r + 1, c);
    dfs(r - 1, c);
    dfs(r, c + 1);
    dfs(r, c - 1);
}


// 从链表中删除指定价值的节点 (可能有多个同值节点，全部删除)
ListNode* deleteNode(ListNode* head, int targetVal) {
    ListNode dummy(0, -1, -1); // 虚拟头节点
    dummy.next = head;
    ListNode* curr = &dummy;
    
    while (curr->next) {
        if (curr->next->val == targetVal) {
            ListNode* temp = curr->next;
            curr->next = temp->next;
            delete temp; // 释放内存
        } else {
            curr = curr->next;
        }
    }
    return dummy.next;
}
```

### 第四题：链表区间翻转与重排

 

描述

 

输入 n 个数，用单链表进行维护。接下来输入两个整数 begin 和 end（代表节点在链表中的位置序号，从1开始）。

 

请完成以下两个操作：

 
1. 奇偶/两两重排：将整个链表的节点进行两两交换（例如原链表 ->2->3->4->5 交换后变为 2->1->4->3->5）。
 
2. 区间反转：在重排后的链表中，将位置从 begin 到 end 的这一段节点进行反转。
 

最后返回操作完成后的链表头指针。

 

请勿提交 main 函数。

 

核心原理： 这道题融合了力扣第24题和第92题。链表操作的万能解药就是：画图 + 引入虚拟头节点（Dummy Node）。 两两交换时需要用到三个指针；而区间翻转的经典做法是“头插法”，即把区间内的节点依次摘下来插入到区间起始位置的最前面。

```cpp
struct ListNode {
    int val;
    ListNode* next;
    ListNode(int x) : val(x), next(nullptr) {}
};


// 操作 1：两两交换链表节点
ListNode* swapPairs(ListNode* head) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;
    
    while (prev->next && prev->next->next) {
        ListNode* first = prev->next;
        ListNode* second = prev->next->next;
        
        // 改变指针指向进行交换
        first->next = second->next;
        second->next = first;
        prev->next = second;
        
        // prev 指针后移两位
        prev = first;
    }
    return dummy.next;
}


// 操作 2：反转指定区间 [begin, end] 的链表
ListNode* reverseBetween(ListNode* head, int left, int right) {
    if (!head || left == right) return head;
    
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;
    
    // 走到 left 的前一个节点
    for (int i = 0; i < left - 1; ++i) {
        prev = prev->next;
    }
    
    ListNode* curr = prev->next;
    // 使用头插法反转区间内的节点
    for (int i = 0; i < right - left; ++i) {
        ListNode* nextTemp = curr->next;
        curr->next = nextTemp->next;
        nextTemp->next = prev->next;
        prev->next = nextTemp;
    }
    
    return dummy.next;
}


// 主逻辑调用
ListNode* processList(ListNode* head, int begin, int end) {
    head = swapPairs(head);
    head = reverseBetween(head, begin, end);
    return head;
}
```

### 第五题：相对名次 【排序，哈希表】

 

描述

 

给定 N 个运动员的成绩记录（成绩为互不相同的整数），请对他们的大小进行排名。

 

对于排名前三名的运动员，请分别输出 "Gold Medal"，"Silver Medal" 和 "Bronze Medal"。

 

从第四名开始，输出其具体的名次（如 "4", "5" 等）。

 

要求：必须按照输入时运动员的原顺序输出他们对应的奖牌或名次。

 

输入

 

第一行输入一个整数

N(1≤N≤104)

。

 

第二行输入 N 个用空格隔开的整数，代表每个运动员的成绩。

 

输出

 

按原序输出每个运动员的名次/奖牌，每个结果用空格隔开。

 

样例输入

```text
5
10 3 8 9 4
```

样例输出

```text
Gold Medal 5 Bronze Medal Silver Medal 4
```

解题思路： 这道题的核心要求是在不改变原数组顺序的情况下输出排名。

 
1. 我们可以用一个额外的数组把成绩拷贝下来，然后将其降序排序。
 
2. 排序后，用一个哈希表（unordered\_map）记录每个成绩对应的名次/奖牌字符串。
 
3. 最后，再次遍历原来的成绩数组，直接从哈希表中查出对应的奖牌打印即可。
 

参考代码：

```cpp
#include <iostream>
#include <vector>
#include <string>
#include <algorithm>
#include <unordered_map>


using namespace std;


int main() {
    int n;
    if (!(cin >> n)) return 0;
    
    vector<int> score(n);
    vector<int> sorted_score(n);
    
    for (int i = 0; i < n; ++i) {
        cin >> score[i];
        sorted_score[i] = score[i];
    }
    
    // 降序排序
    sort(sorted_score.rbegin(), sorted_score.rend());
    
    // 哈希表记录：成绩 -> 名次字符串
    unordered_map<int, string> rank_map;
    for (int i = 0; i < n; ++i) {
        if (i == 0) rank_map[sorted_score[i]] = "Gold Medal";
        else if (i == 1) rank_map[sorted_score[i]] = "Silver Medal";
        else if (i == 2) rank_map[sorted_score[i]] = "Bronze Medal";
        else rank_map[sorted_score[i]] = to_string(i + 1);
    }
    
    // 按照原顺序输出
    for (int i = 0; i < n; ++i) {
        cout << rank_map[score[i]] << (i == n - 1 ? "" : " ");
    }
    cout << "\n";
    
    return 0;
}
```

### 第六题：最小连线长度 【最小生成树，图论】

 

描述

 

在一个二维坐标系中给定 N 组顶点的坐标 (x, y)。要求用线把它们连起来，使得任意两个点都能直接或间接连通。

 

线的长度定义为两个点之间的曼哈顿距离：即

∣x1​−x2∣+∣y1​−y2​∣

。

 

任意两个点之间可以选择连接也可以不连接。求能使所有点连通的最短连线总长度。

 

输入

 

第一行包含一个整数

N(1≤N≤1000)

，表示顶点数量。

 

接下来 N 行，每行包含两个整数 x 和 y，表示顶点的坐标。

 

输出

 

输出一个整数，表示所有线长度总和的最小值。每个输出结果为独立的一行，结尾有换行。

 

解题思路：

 

这是一个经典的“最小生成树（MST）”问题。因为任意两个点之间都可以连线，所以这是一个完全图（稠密图）。

 

对于稠密图，Prim算法（时间复杂度 O(N^2)）通常比 Kruskal 算法（需要对所有边排序，边数为 N^2，排序复杂度 O(N^2 \\log N)）更高效。我们维护一个 minDist 数组，记录当前已连通集合到未连通点的最短曼哈顿距离，每次贪心地把距离最近的点加入集合中即可。

 

参考代码：

```cpp
#include <iostream>
#include <vector>
#include <cmath>


using namespace std;


int main() {
    int n;
    if (!(cin >> n)) return 0;
    
    vector<pair<int, int>> points(n);
    for (int i = 0; i < n; ++i) {
        cin >> points[i].first >> points[i].second;
    }


    // minDist[i] 表示节点 i 到当前生成树的最短距离
    vector<int> minDist(n, 1e9);
    vector<bool> visited(n, false);
    minDist[0] = 0; // 从节点0开始构建生成树
    long long total_weight = 0;


    // Prim 算法核心
    for (int i = 0; i < n; ++i) {
        int u = -1;
        // 找到未访问节点中，距离生成树最近的节点
        for (int j = 0; j < n; ++j) {
            if (!visited[j] && (u == -1 || minDist[j] < minDist[u])) {
                u = j;
            }
        }
        
        visited[u] = true;
        total_weight += minDist[u];


        // 更新新加入节点 u 后，周围未访问节点的 minDist
        for (int v = 0; v < n; ++v) {
            if (!visited[v]) {
                int dist = abs(points[u].first - points[v].first) + 
                           abs(points[u].second - points[v].second);
                if (dist < minDist[v]) {
                    minDist[v] = dist;
                }
            }
        }
    }
    
    cout << total_weight << "\n";
    return 0;
}
```

### 第七题：小孩子排队 【贪心算法】

 

描述

 

给定 N 个小孩子，每个小孩子各自带着一个整数，这些整数可能相同，也可能不同。

 

现在要求让这些小孩子排成一条队伍，要求任意相邻的两个小孩子之间必须带着不同的整数。

 

请判断能否排列出符合要求的队伍。

 

输入

 

第一行为整数 N。

 

第二行为 N 个整数，表示每个小孩子带着的数字，以空格隔开。

 

输出

 

如果能排列出这样的队伍，输出 Yes；否则输出 No。结尾有换行。

 

样例输入

```text
4
1 1 1 2
```

样例输出

```text
No
```

解题思路：

 

这题不需要我们真的把队伍排出来，只问“能否排出来”。

 

这里有一个基于鸽巢原理的数学结论：

 

如果数组中出现次数最多的那个数字，它的数量超过了数组总长度的一半（向上取整），那么无论怎么排，绝对会有两个相同的数字挨在一起。反之，只要最大频次满足要求，就一定能排出来（比如采用插空法）。

 

所以，公式就是判断最大频次 max\_freq 是否满足

max\_freq≤⌈N/2⌉即max\_freq≤(N+1)/2

。

 

参考代码：

```cpp
#include <iostream>
#include <unordered_map>
#include <algorithm>


using namespace std;


int main() {
    int n;
    if (!(cin >> n)) return 0;
    
    unordered_map<int, int> freq;
    int max_f = 0; // 记录出现最多的数字的频次
    
    for (int i = 0; i < n; ++i) {
        int val;
        cin >> val;
        freq[val]++;
        max_f = max(max_f, freq[val]);
    }


    // 核心贪心/数学判定
    if (max_f <= (n + 1) / 2) {
        cout << "Yes\n";
    } else {
        cout << "No\n";
    }
    
    return 0;
}
```

### 第八题：段式回文 【双指针，字符串匹配】

 

描述

 

给定一个字符串 S，请将其分割成尽可能多的子字符串（即分成 k 段），使得这 k 段字符串整体构成一个“回文段”序列。

 

回文段序列的定义为：分割后的字符串数组

(P1​,P2​,...,Pk​)

满足

Pi​\==Pk−i+1​

（对于任意

1≤i≤k

）。

 

例如：machine 返回 1（因为无法对称分割，只能作为完整的一段）；abdabd 返回 2（分为 abd 和 abd）；aaaa 返回 4（分为 a, a, a, a）。

 

求最大的分割段数 k。

 

输入

 

输入包含一个字符串 S，仅包含小写英文字母。

 

输出

 

输出最大的段数 k。

 

样例输入

```text
abcfguyfgabc
```

样例输出

```text
5
```

(注：分割为 "abc", "fg", "uy", "fg", "abc")

 

解题思路： 这道题可以用贪心+双指针来做。 我们从字符串的左右两端开始，逐渐积累左边的子串（前缀）和右边的子串（后缀）。 贪心策略： 只要前缀和后缀相等了，我们就立刻把它们切下来当作两段回文段（局部最优必定能构成全局最优的回文分割），然后清空子串，继续往中间找。

 

参考代码：

```cpp
#include <iostream>
#include <string>


using namespace std;


int main() {
    string s;
    if (!(cin >> s)) return 0;


    int n = s.length();
    int ans = 0;
    string left_str = "", right_str = "";


    // 双指针从两端向中间逼近
    for (int i = 0, j = n - 1; i <= j; ++i, --j) {
        left_str = left_str + s[i];
        right_str = s[j] + right_str;


        // 如果前后缀匹配了
        if (left_str == right_str) {
            if (i == j) {
                // 如果刚好是在最中间相遇，算作独立的一段
                ans += 1;
            } else {
                // 切割出两段
                ans += 2;
            }
            // 清空，准备匹配下一轮
            left_str = "";
            right_str = "";
        }
    }
    
    // 如果最后还有剩余无法对称匹配的字符，只能把它当作中间的一整个段
    if (!left_str.empty()) {
        ans += 1;
    }


    cout << ans << "\n";
    return 0;
}
```

### 第九题：道路能见度 【Dijkstra，最短路径变形】

 

描述

 

有 n 个城市和 m 条有向道路，每条道路都有一个“能见度”权值。

 

小明要从 1 号城市回到 n 号城市。如果在行进路线上，某条道路的能见度低于当天的天气能见度阈值 w，则小明无法走这条道路。

 

问：当天的天气能见度阈值 w至少要多大，小明才“恰好”无法从 1 号城市到达 n 号城市？换句话说，求出 1 号城市到 n 号城市的所有可能路径中，“路径上的最小能见度”的最大值。如果无论如何都无法到达 n 号城市，则输出 T\_T。

 

输入

 

第一行包含两个整数 n 和 m。

 

接下来 m 行，每行三个整数 u, v, c，表示从城市 u 到城市 v 有一条能见度为 c 的单向道路。

 

输出

 

输出一个整数，表示小明回家的最高连通阈值。如果没有路径，输出 T\_T。

 

解题思路： 这道题披着“求最小能见度”的外衣，实际上是在求\*\*“从起点到终点的所有路径中，最小边权的最大值”\*\*（通常被称为最大瓶颈路或最大容量路）。

 
- 传统的 Dijkstra 算法是：每次找“距离起点最近”的点，通过它去更新其他点（寻找最短路）。
 
- 本题的变体 Dijkstra 是：每次找\*\*“当前连通容量最大”的点，通过它去更新其他点。我们需要把默认的最小堆改成最大堆\*\*，同时维护一个 max\_bottleneck 数组，记录到达每个节点所能保持的“最大最小能见度”。
 

C++ 参考代码：

```cpp
#include <iostream>
#include <vector>
#include <queue>
#include <algorithm>


using namespace std;


const int INF = 1e9 + 7;


int main() {
    int n, m;
    if (!(cin >> n >> m)) return 0;
    
    // 邻接表表示图：adj[u] 存储 pair<目标节点, 能见度权值>
    vector<vector<pair<int, int>>> adj(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v, c;
        cin >> u >> v >> c;
        adj[u].push_back({v, c});
    }


    // 记录到达每个节点的最大瓶颈（最小能见度的最大值）
    vector<int> max_bottleneck(n + 1, -1);
    
    // 最大堆，存储 pair<当前路径的瓶颈值, 当前节点>
    priority_queue<pair<int, int>> pq;
    
    // 起点初始化
    max_bottleneck[1] = INF; // 假设起点自身的能见度无穷大
    pq.push({INF, 1});
    
    while (!pq.empty()) {
        int current_bottleneck = pq.top().first;
        int u = pq.top().second;
        pq.pop();
        
        // 如果当前拿到的瓶颈值已经小于记录的最大瓶颈，说明是旧状态，直接丢弃
        if (current_bottleneck < max_bottleneck[u]) continue;
        
        // 遍历相邻节点
        for (auto& edge : adj[u]) {
            int v = edge.first;
            int weight = edge.second;
            
            // 经过节点 u 到达 v 的瓶颈，是由 u 的瓶颈和当前边权决定的短板
            int new_bottleneck = min(current_bottleneck, weight);
            
            // 如果发现了能让到达 v 的瓶颈变得更大的路径，更新并入队
            if (new_bottleneck > max_bottleneck[v]) {
                max_bottleneck[v] = new_bottleneck;
                pq.push({new_bottleneck, v});
            }
        }
    }
    
    // 输出结果
    if (max_bottleneck[n] == -1) {
        cout << "T_T\n";
    } else {
        cout << max_bottleneck[n] << "\n";
    }
    
    return 0;
}
```

### 第十题：括号染色 【动态规划，区间DP】

 

描述

 

给定一个由 ( 和 ) 组成的完全正确匹配的括号序列。现在要给这些括号染色。

 

染色的规则如下：

 
1. 每个括号有三种染色情况：不染色、染红色、染蓝色。
 
2. 相互匹配的一对括号，不能同时不染色，也不能同时染同一种颜色（即必须有且仅有一个括号被染色）。
 
3. 相邻的两个括号不能染成相同的颜色（但相邻的两个括号可以同时不染色）。
 

求对给定的括号序列进行染色的合法方案数。由于方案数可能很大，请输出答案除以 1000000007 的余数。

 

输入

 

输入一行字符串，表示匹配好的括号序列。字符串长度不超过 700。

 

输出

 

输出一个整数，代表合法染色方案数对 1000000007 取模的结果。

 

样例输入

```text
(())
```

样例输出

```text
12
```

解题思路： 这是一道非常经典的树形区间 DP，核心在于理清复杂的染色和相邻规则。 根据题意，颜色可以分为三种：0（不染色），1（红色），2（蓝色）。

 
- 规则 1（匹配对规则）：一对相匹配的括号，必须是一个染色、另一个不染色。因此，合法的颜色组合只能是 (0, 1), (0, 2), (1, 0), (2, 0)。
 
- 规则 2（相邻规则）：相邻的两个括号不能同色（比如不能是 1 和 1，2 和 2），但可以同时不染色（即 0 和 0 是合法的）。
 

我们可以使用递归加上记忆化（Memoization）求解。首先使用栈预处理出每个左括号匹配的右括号位置 match\[i\]。 定义递归函数 dfs(l, r) 返回一个 3x3 的二维数组，其中 res\[i\]\[j\] 表示将区间 \[l, r\] 的左端点染成颜色 i，右端点染成颜色 j 时的合法方案数。 转移方程分为两种情况：

 
1. match\[l\] == r（整个区间被一对匹配的括号完全包裹）：我们枚举外层这对括号的颜色组合，再枚举内部 dfs(l+, r-1) 的颜色，满足相邻规则即可累加方案数。
 
2. match\[l\] < r（区间是由多个并列的匹配括号组成的）：我们在匹配点 m = match\[l\] 处将其劈成两半，将 dfs(l, m) 和 dfs(m+1, r) 结合起来，结合时仅需保证断点处的颜色 c\_m 和 c\_{m+1} 满足相邻规则即可。
