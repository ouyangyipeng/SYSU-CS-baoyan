### 动物园 【C++多态】

 

题目描述

 

多态现在一般的用法，就是拿一个父类的指针去调用子类中被重写的方法。

 

现在给出情景：动物园里有猫和狗，管理员小明注意到，狗叫声为"W"，猫叫声为"M"，而且一开始猫狗按照顺序叫，接着所有狗依次叫，然后所有猫依次叫。

 

输入动物园里的动物个数

n

，然后依次输入每个动物是狗还是猫，若输入0，则表明该动物是狗，若输入1，则表明该动物是猫。

 

请根据主函数完成 animal 类，dog 类，cat 类的定义。请勿提交main函数

 
- animal 包含两个成员函数 void shout() 和 int get\_type()。
 
- dog 继承 animal，并且 shout() 发出 W，get\_type() 返回 0。
 
- cat 继承 animal，并且 shout() 发出 M，get\_type() 返回 1。
 

样例输入

```text
4
0 1 1 0
```

样例输出

```text
W
M
M
W
W
W
M
M
```

解题思路： 要实现“父类指针调用子类重写的方法”，必须在父类 animal 中将相关函数声明为虚函数（virtual）。这里 shout() 和 get\_type() 在父类中可以声明为纯虚函数，使其成为抽象类。子类 dog 和 cat 则分别重写这两个方法。

 

代码实现：

```cpp
#include <iostream>


class animal {
public:
// 声明为纯虚函数，实现多态
virtual void shout() = 0;
virtual int get_type() = 0;
// 多态基类应当拥有虚析构函数
virtual ~animal() {} 
};


class dog : public animal {
public:
void shout() override {
    std::cout << "W\n";
}
int get_type() override {
    return 0;
}
};


class cat : public animal {
public:
void shout() override {
    std::cout << "M\n";
}
int get_type() override {
    return 1;
}
};
```

### 多继承的构造顺序 【C++多继承，虚继承】

 

描述

 

本题考查C++中类在多继承中的构造顺序，请根据给出的输出推测类之间的关系，并完成类的声明。

 

main函数和类的实现已经提供（见答题区域），只需要在 Inheritance.hpp 中编写类的声明即可。

 

需要完成的类声明有

```text
class baseA;
class baseB;
class derivedA;
class derivedB1;
class derivedB2;
class C;
```

请勿提交main函数。

 

输出结果已加入依赖于输入的某种标识，无需关注。正常输出部分从第三行开始。

 

输入

```text
10
```

输出

```text
<某种依赖于输入的标识>


creat base A
base A


creat base B
base B


creat derived A
base A
derived A


creat derived B1
base B
derived B1


creat derived B2
base B
derived B2


creat C
base B
derived B2
derived B1
base A
derived A
C
```

解题思路： 这道题需要通过构造函数的输出顺序来反推类的继承关系。C++ 中类的构造顺序规则为：

 
1. 虚基类（Virtual Base Classes）的构造函数最先被调用（按继承深度优先、从左到右的顺序）。
 
2. 然后调用非虚基类的构造函数（严格按照派生类声明中继承列表的先后顺序）。
 
3. 最后执行派生类自己的构造函数。
 

推导过程：

 
- 从 creat C 的输出可以看出，base B 只被构造了一次，并且是最先构造的。而 C 的父类 derived B2 和 derived B1 都继承自 base B。为了避免 base B 被构造两次（菱形继承问题），derived B1 和 derived B2 必须虚继承（virtual public）自 base B。
 
- C 构造时，接下来的顺序是 derived B2 -> derived B1 -> base A -> derived A。这说明 C 的继承列表顺序严格为：public derivedB2, public derivedB1, public derivedA。
 

代码实现（类的声明）：

```cpp
// 基础类
class baseA {
public:
    baseA();
};


class baseB {
public:
    baseB();
};


// 单继承
class derivedA : public baseA {
public:
    derivedA();
};


// 虚继承 baseB，保证在多继承中 baseB 只被实例化一次
class derivedB1 : virtual public baseB {
public:
    derivedB1();
};


class derivedB2 : virtual public baseB {
public:
    derivedB2();
};


// 多继承：严格按照输出的非虚基类构造顺序进行声明
class C : public derivedB2, public derivedB1, public derivedA {
public:
    C();
};
```

### 碰撞 【哈希表】

 

描述

 

著名的应用于字符串的hash算法 ELFHash 流程如下：

```c
unsigned ELFHash(const char *str)
{
    unsigned h = 0, g;
    while (*str)
    {
        h = (h << 4) + *str++;
        if (g = h & 0xf0000000)
            h ^= g >> 24;
        h &= ~g;
    }
    return h;
}
```

现在，你需要实现一个hash表，你必须使用ELFHash函数和用链地址法解决冲突

 

链地址解决冲突的原理是在hash表的每个位置都有一个链表指针，每一个新加入的元素插入到链表末尾，冲突次数就是插入前的链表长度。

 

输入

 

第一行包含两个整数 "n m"，n表示操作数目，m表示hash表大小。

 

接下来n行，每行包含一个操作 "op str"，其中op为操作类型，str为字符串。str长度不超过10，由大小写字母组成。

 

当op为0时，插入str到hash表中。

 

当op为1时，在hash表中查询str。

 

输出

 

对于每个操作，当op=0时，如果str已经存在，则输出 "existed"，否则输出 "insert ok"；

 

当op=1时，如果str已经存在，输出插入str时的冲突次数，否则输出 "-1"。

 

样例输入

```text
8 10
0 a
0 k
0 u
0 k
1 a
1 k
1 u
1 b
```

样例输出

```text
insert ok
insert ok
insert ok
existed
0
1
2
-1
```

注：每个输出结果为独立的一行，结尾有换行。

 

解题思路： 题意要求使用链地址法（Separate Chaining）来解决哈希冲突。所谓链地址法，就是哈希表的底层是一个数组，数组的每个元素都是一个链表（或动态数组 std::vector）。

 
- 当计算出一个字符串的 ELFHash % m （即数组下标）后，我们去对应的链表中查找。
 
- 如果插入时找到该元素，说明已存在；如果没找到，将其追加到链表末尾。题目中说的“冲突次数就是插入前的链表长度”，恰好对应了该元素插入链表后所在的索引位置（从0开始）。
 
- 如果查询时找到该元素，直接返回它在链表中的索引即可；未找到返回 \-1。

```cpp
#include <iostream>
#include <vector>
#include <string>


using namespace std;


// 题目提供的 ELFHash 算法
unsigned ELFHash(const char *str) {
    unsigned h = 0, g;
    while (*str) {
        h = (h << 4) + *str++;
        if (g = h & 0xf0000000)
            h ^= g >> 24;
        h &= ~g;
    }
    return h;
}


int main() {
    int n, m;
    // 读取操作数 n 和哈希表大小 m
    if (!(cin >> n >> m)) return 0;
    
    // 使用 vector 的 vector 来模拟链地址法
    vector<vector<string>> hashTable(m);
    
    for (int i = 0; i < n; ++i) {
        int op;
        string str;
        cin >> op >> str;
        
        // 计算哈希值并对 m 取模得到索引
        unsigned hash_val = ELFHash(str.c_str());
        int idx = hash_val % m;
        
        // 在对应位置的链表中查找 str
        int pos = -1; // 记录 str 在链表中的位置
        for (size_t j = 0; j < hashTable[idx].size(); ++j) {
            if (hashTable[idx][j] == str) {
                pos = j;
                break;
            }
        }
        
        if (op == 0) { // 插入操作
            if (pos != -1) {
                cout << "existed\n";
            } else {
                hashTable[idx].push_back(str);
                cout << "insert ok\n";
            }
        } else if (op == 1) { // 查询操作
            cout << pos << "\n";
        }
    }
    return 0;
}
```

### 循环字符串 【字符串匹配】

 

描述

 

给定两个字符串s1和s2，要求判定s2是否能够被s1做循环移位 (rotate) 得到的字符串包含。说明：字符串s1和s2中不包含空格，每个字符串至少包含一个字符。

 

例如：给定S1= AABCD，S2=CDAA，则返回True；

 

给定s1=ABCD，S2=ACBD，则返回False

 

输入

 

第一行为整数n。

 

第2到n+1行为n个输入数据，每行包括两个字符串，字符串s1和字符串s2，字符串之间用空格隔开。字符串由大小写字母、数字组成。s2的长度小于等于s1的长度。

 

输出

 

针对每个例子，如果s2能够被s1做循环移位得到的字符串包含，输出True，否则输出False；每个输出结果为独立的一行，结尾有换行。

 

样例输入

```text
2
AABCD CDAA
ABCD ACBD
```

样例输出

```text
True
False
```

解题思路：

 

判断

s2​

是否是

s1​

循环移位后的子串，有一个非常巧妙且常用的解法：将

s1​

与自身拼接一次，变成

s1​+s1​

。

 

由于

s1​+s1​

包含了

s1​

所有可能的循环移位结果，所以问题就简化为了：判断

s2​

是否是

s1​+s1​

的子串。

 

例如：

s1​\=AABCD

，拼接后变成

AABCDAABCD

。你会发现

CDAA

刚好就包含在这个拼接后的字符串中。

```cpp
#include <iostream>
#include <string>


using namespace std;


int main() {
    int n;
    // 读取测试用例数量
    if (cin >> n) {
        while (n--) {
            string s1, s2;
            cin >> s1 >> s2;
            
            // 将 s1 拼接自身，这样就包含了所有循环移位的情况
            string double_s1 = s1 + s1;
            
            // 使用 string 类的 find 方法查找 s2 是否为 double_s1 的子串
            if (double_s1.find(s2) != string::npos) {
                cout << "True\n";
            } else {
                cout << "False\n";
            }
        }
    }
    return 0;
}
```

### 训练机器人 【深度优先算法，递归】

 

描述

 

C博士制造了一个机器人小R，他想通过训练提高小R的AI，于是他在实验室地面上画了由N行M列方格组成的迷宫，并在有些方格中放置了障碍物。小R从指定的起点方格开始，要走到指定的目标方格。

 

小R每次可以从一个方格走到和他当前位置相邻的没有障碍物的方格，两个方格有共同的边称为相邻。C博士设置的障碍物保证任意两个没有障碍物的空格有且只有一条不经过重复方格的路径。在小R沿着这条唯一路径走到目标方格的过程中，如果它经过的分岔路口越多，则对小R的训练强度越高。

 

所谓分岔路口是指路径上这样的一种方格，当走到这一方格时，和这一方格相邻的有多于一个没走过且没有障碍物的方格。

 

给出N行M列的迷宫，以及起点和目标位置，请你帮C博士计算小R沿着正确路径走到目标方格，总共要经过多少个分岔路口。

 

输入

 

输入的第一行是一个整数T（T <= 120），代表输入数据的组数。

 

每组数据的第一行是两个整数N和M（1 <= N, M <= 50），分别代表迷宫的行数和列数。

 

接下来的N行，每行含有M个字符，给出了迷宫的描述。

 
- 字符 . 表示对应方格为空，
 
- X 表示对应方格有障碍物，
 
- R 表示小R的起点，
 
- T 表示小R的目标方格。
 

输入保证每组样例有且只有一个R，有且只有一个T，任意两个没有障碍物的空格之间有且只有一条不经过重复方格的路径。

 

输出

 

对于每组数据，输出一行，包含一个整数，表示小R从起点到目标要经过多少分岔路口。每个输出结果为独立的一行，结尾有换行。

 

样例输入

```text
2
2 3
T.R
.X.
3 3
...
XRX
..T
```

样例输出

```text
1
2
```

解题思路： 题目明确指出“任意两个没有障碍物的空格有且只有一条不经过重复方格的路径”，这意味着迷宫的有效路径其实是一棵无环树。我们要找的“分岔路口”，即在探索路径的过程中，当前节点抛开“来时的路”（父节点），其相邻的、可走的节点数量大于1。

 

我们可以直接使用深度优先搜索 (DFS) 解决：

 
1. 从起点 R 开始向下递归，同时记录它的“前驱节点坐标”(避免往回走) 和“当前已经经过的分岔路口数”。
 
2. 对于到达的每一个格子，统计其周围 4 个方向上可走的格子数量（跳过前驱节点和障碍物）。如果数量 \> 1，说明这是一个分岔路口，计数器 \+ 1。
 
3. 当搜索遇到终点 T 时，直接返回累积的分岔路口数量。

```cpp
#include <iostream>
#include <vector>
#include <string>


using namespace std;


int N, M;
vector<string> maze;


// 上下左右四个方向的位移
int dr[] = {-1, 1, 0, 0};
int dc[] = {0, 0, -1, 1};


// dfs函数：r/c为当前坐标，pr/pc为前驱节点坐标，forks为目前累计的分岔路口数
int dfs(int r, int c, int pr, int pc, int forks) {
    // 走到目标节点，返回分岔路口总数
    if (maze[r][c] == 'T') return forks;
    
    // 统计当前节点周围可走的且未走过(非前驱)的节点数
    int valid_next = 0;
    for (int i = 0; i < 4; ++i) {
        int nr = r + dr[i];
        int nc = c + dc[i];
        // 不越界且不是障碍物
        if (nr >= 0 && nr < N && nc >= 0 && nc < M && maze[nr][nc] != 'X') {
            // 不能走回头路
            if (nr != pr || nc != pc) {
                valid_next++;
            }
        }
    }
    
    // 如果有大于1个可走的后续节点，说明是个分岔路口
    int new_forks = forks + (valid_next > 1 ? 1 : 0);
    
    // 继续 DFS 搜索
    for (int i = 0; i < 4; ++i) {
        int nr = r + dr[i];
        int nc = c + dc[i];
        if (nr >= 0 && nr < N && nc >= 0 && nc < M && maze[nr][nc] != 'X') {
            if (nr != pr || nc != pc) {
                int res = dfs(nr, nc, r, c, new_forks);
                // 找到了通往终点的路径，提前返回
                if (res != -1) return res;
            }
        }
    }
    
    return -1; // 走不通返回-1
}


void solve() {
    cin >> N >> M;
    maze.resize(N);
    int sr = -1, sc = -1;
    
    // 读取迷宫并寻找起点 R
    for (int i = 0; i < N; ++i) {
        cin >> maze[i];
        for (int j = 0; j < M; ++j) {
            if (maze[i][j] == 'R') {
                sr = i;
                sc = j;
            }
        }
    }
    
    // 起点没有前驱，初始前驱坐标设为(-1, -1)
    cout << dfs(sr, sc, -1, -1, 0) << "\n";
}


int main() {
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

### 拓扑排序 【拓扑排序】

 

描述

 

小吴在准备中大研究生复试，他复习到了一个简单的算法：拓扑排序。现在，他想把这个算法应用到一个有向图上。所以他想请你告诉他怎么做。该图不一定是有向无环图。

 

输入

 

第一行为整数T，为测试样例数目。

 

接下来有T个测试样例，对于每个测试样例：

 

第一行为两个整数 "n m"，n为顶点个数（顶点标号从1到n），m为有向边的数目。

 

接下来，共m行，每行包含两个不相等的整数i和j，表示存在一条从顶点i指向顶点j的有向边（可能存在重边，即可能存在两行输入一样）。

 

输出

 

对于每个测试用例输出一行，如果该图为无环图，输出字典序最小的拓扑序，每两个数字之间用空格隔开，否则输出 It's not a DAG!。行末无多余空格，每个输出结果为独立的一行，结尾有换行。

 

样例输入

```text
2
5 4
1 2
1 3
2 4
4 5
10 10
1 2
2 4
3 4
```

解题思路： 题意是判断字符串中是否存在连续的两段完全相同的子串（即 A = BB 的形式）。 因为题目给定的字符串长度极小（不超过 50），我们可以直接使用暴力枚举：

 
1. 枚举子串 B 的长度 len，从  枚举到 S.length() / 2。
 
2. 枚举子串的起始位置 i，从 0 开始。
 
3. 检查从 i 开始的长度为 len 的子串，是否与从 i + len 开始的长度为 len 的子串完全相等。一旦找到直接返回 YES。

```cpp
#include <iostream>
#include <string>
#include <vector>


using namespace std;


void solve() {
    string s;
    cin >> s;
    int n = s.length();
    
    // 枚举 B 的长度 len
    for (int len = 1; len <= n / 2; ++len) {
        // 枚举起始位置 i
        for (int i = 0; i <= n - 2 * len; ++i) {
            bool match = true;
            // 逐个字符比较 B 和紧跟其后的 B
            for (int j = 0; j < len; ++j) {
                if (s[i + j] != s[i + len + j]) {
                    match = false;
                    break;
                }
            }
            if (match) {
                cout << "YES\n";
                return;
            }
        }
    }
    cout << "NO\n";
}


int main() {
    int t;
    if (cin >> t) {
        while (t--) {
            solve();
        }
    }
    return 0;
}
```

### 括号匹配 【栈的使用，动态规划】

 

描述

 

合法的括号序列可以递归定义如下：

 

(i) () 是合法的； (ii) 如果 s 是合法的，那么 (s) 也是合法的； (iii) 如果 s 和 t 是合法的，那么 st 也是合法的； (iv) 任何一个合法括号序列都可以由 (i) (ii) (iii) 三条规则生成。

 

例如 (()) 和 (()()) 都是合法的，而 (() 和 ))(( 则都不合法。

 

一个字符串S删掉其中若干个（可以是零个）字符，得到的字符串称为S的子序列。例如 adf 是 abcdef 的子序列。

 

对于一个只含有 ( 和 ) 的字符串，你的任务是计算其中有多少个不同的子序列是合法的括号序列。

 

输入

 

输入有多组数据(不大于100组)，每行代表一组数据，每组数据只有一个字符串S。S的长度在1到100之间，S中只含有 ( 和 )。输入以 # 结束。

 

输出

 

对于每组数据，输出S中不同的合法括号子序列的数量，答案可能很大，你只需要输出答案除以 1000000007 的余数。每个输出结果为独立的一行，结尾有换行。

 

样例输入

```text
()()
(()
)()((()))
#
```

样例输出

```text
2
1
5
```

提示

 

第一个测例中，一共有三种删除方法可以得到合法子串：1. 不删除；2. 删除前两个字符；3.删除后两个字符。但是第2,3种方法得到的子串是相同子串，所以不同的合法子序列有 2 个。

 

解题思路： 这道题的难点在于“去重”。比如针对 ()()，如果不做特殊处理，删除前两个字符和删除后两个字符都会得到 ()，会被错误地计算两次。

 

为了不重不漏地统计“合法的不同子序列”，我们需要借助子序列自动机的思想。其核心法则是：在匹配任何字符时，永远只贪心地选择当前位置之后出现的“第一个”目标字符。这样就能保证同一个生成的子串在原串中对应着唯一的一条匹配路径。

 

我们可以定义动态规划：

 
- 状态定义：dp\[i\]\[k\] 表示当前匹配到原串的第 i 个位置，且当前拥有的未匹配左括号 ( 数量为 k 时，后续能组成的合法序列数量。
 
- 预处理： 利用一个 nxt\[i\]\[0/1\] 数组，快速记录每个位置之后，第一个 ( 和第一个 ) 的下标。
 
- 状态转移：
 
- 如果我们走到了 k == 0 的状态（且不是起点），说明我们已经成功闭合了一段合法括号序列，方案数 +1（表示可以在此处停止）。
 
- 同时，我们还可以选择继续往后拼接：
 
- 如果后面还有 (，可以跳到下一个 ( 的位置，此时 k + 1。
 
- 如果 k > 0 且后面还有 )，可以跳到下一个 ) 的位置，此时 k - 1。
 
- 起始点设为虚拟下标 \-1，初始 k = 0。

```cpp
#include <iostream>
#include <string>
#include <vector>
#include <cstring>


using namespace std;


const int MOD = 1000000007;


int nxt[105][2];
int memo[105][105];
string s;


// i 是当前匹配到的字符下标，k 是当前未匹配的左括号数量
int dfs(int i, int k) {
    // 记忆化搜索：下标 + 1 是为了防止出现 -1 越界
    if (memo[i + 1][k] != -1) {
        return memo[i + 1][k];
    }
    
    int ans = 0;
    // 如果 k == 0 且不是虚拟起点，说明形成了一个完整的合法子序列，算作一种方案
    if (k == 0 && i != -1) {
        ans = 1; 
    }
    
    // 选择接下来的第一个 '('
    int next_open = nxt[i + 1][0];
    if (next_open != -1) {
        ans = (ans + dfs(next_open, k + 1)) % MOD;
    }
    
    // 如果存在未闭合的左括号，且接下来有 ')'
    int next_close = nxt[i + 1][1];
    if (k > 0 && next_close != -1) {
        ans = (ans + dfs(next_close, k - 1)) % MOD;
    }
    
    return memo[i + 1][k] = ans;
}


int main() {
    // 持续读取直到遇到 #
    while (cin >> s && s != "#") {
        int n = s.length();
        
        // nxt[i][0] 表示 i 位置及之后第一个 '(' 的下标
        // nxt[i][1] 表示 i 位置及之后第一个 ')' 的下标
        int last_open = -1, last_close = -1;
        for (int i = n - 1; i >= 0; --i) {
            if (s[i] == '(') last_open = i;
            if (s[i] == ')') last_close = i;
            nxt[i][0] = last_open;
            nxt[i][1] = last_close;
        }
        
        // 处理边界（当超出字符串长度时）
        nxt[n][0] = -1;
        nxt[n][1] = -1;
        
        memset(memo, -1, sizeof(memo));
        
        // 从虚拟起点 -1 开始，此时匹配到的左括号数为 0
        cout << dfs(-1, 0) << "\n";
    }
    return 0;
}
```
