04 碰撞 【 哈希表 】
 实时评测

描述
著名的应用于字符串的hash算法 ELFHash 流程如下：

unsigned ELFHash(const char *str)
{
	unsigned h = 0, g;
	while (*str)
	{
		h = (h << 4) + *str++;
		if (g = h & 0xf0000000)
			h ^= g >> 24;
		h &= ~g;
	}
	return h;
 
}
​
现在，你需要实现一个hash表，你必须使用ELFHash函数和用链地址法解决冲突

链地址解决冲突的原理是在hash表的每个位置都有一个链表指针，每一个新加入的元素插入到链表末尾，冲突次数就是插入前的链表长度。

输入
第一行包含两个整数“n m”，n表示操作数目，m表示hash表大小。

接下来n行，每行包含一个操作“op str”，其中op为操作类型，str为字符串。str长度不超过10，由大小写字母组成。

当op为0时，插入str到hash表中。

当op为1时，在hash表中查询str。

输出
对于每个操作， 当op=0时，如果str已经存在，则输出“existed”，否则输出“insert ok”；

当op=1时，如果str已经存在，输出插入str时的冲突次数，否则输出“-1”。

样例输入
8 10
0 a
0 k
0 u
0 k
1 a
1 k
1 u
1 b
​
样例输出
insert ok
insert ok
insert ok
existed
0
1
2
-1
​
注：每个输出结果为独立的一行，结尾有换行。

10 括号匹配 【 栈的使用，动态规划 】
 实时评测

描述
合法的括号序列可以递归定义如下：

（i）()是合法的；

（ii）如果S是合法的，那么(S)也是合法的；

（iii）如果S和T是合法的，那么ST也是合法的；

（iv）任何一个合法括号序列都可以由（i）（ii）（iii）三条规则生成.

例如(())和(()())都是合法的，而(()和))((则都不合法.

一个字符串S删掉其中若干个（可以是零个）字符，得到的字符串称为S的子序列. 例如adf是abcedf的子序列.

对于一个只含有(和)的字符串，你的任务是计算其中有多少个不同的子序列是合法的括号序列.

输入
输入有多组数据(不大于100组)，每行代表一组数据，每组数据只有一个字符串S. S的长度在1到100之间，S中只含有(和). 输入以#结束.

输出
对于每组数据，输出S中不同的合法括号子序列的数量，答案可能很大，你只需要输出答案除以1000000007的余数。每个输出结果为独立的一行，结尾有换行。

样例输入
()()
(()
)(()(())
#
​
样例输出
2
1
5
​
提示
第一个测例中，一共有三种删除方法可以得到合法子串：1. 不删除；2. 删除前两个字符；3.删除后两个字符。但是第2,3种方法得到的子串是相同子串，所以不同的合法子序列有2个。
