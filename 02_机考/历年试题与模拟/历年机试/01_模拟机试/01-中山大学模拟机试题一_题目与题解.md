# 中山大学模拟机试题一_题目与题解
## 第一题：深拷贝字符串类

 

### 题目描述

 

请实现一个 Text 类，类内部必须使用 char\* 保存字符串，不能直接使用 std::string 作为数据成员。

 

要求实现默认构造函数、Text(const char\*) 构造函数、拷贝构造函数、赋值运算符、析构函数、setFirst(char) 和 c\_str()。拷贝构造和赋值运算必须进行深拷贝。

 

### 输入格式

 

第一行输入字符串 A，第二行输入字符串 B。字符串不含空格，长度不超过 1000。

 

### 输出格式

 

依次输出 x 的内容、拷贝构造得到的 y 修改首字符后的内容、赋值运算得到的 z 修改首字符后的内容、再次输出 x。每行一个字符串。

 

### 测试用例

 

输入：

```text
hello
world
```

输出：

```text
hello
Xello
Yello
hello
```

### 题解方法

 

这是典型 Rule of Three：析构函数释放 data；拷贝构造重新申请内存并复制字符；赋值运算符先检查 this == &other，再申请新空间、释放旧空间、更新成员并返回 \*this。赋值时建议先申请新内存，再释放旧内存。

 

### 完整 C++ 代码

```cpp
#include <cstring>
#include <iostream>
#include <string>
using namespace std;


class Text {
private:
    char* data_;


public:
    Text() : data_(new char[1]{'\0'}) {}


    explicit Text(const char* s) {
        if (s == nullptr) {
            data_ = new char[1]{'\0'};
            return;
        }
        const size_t len = strlen(s);
        data_ = new char[len + 1];
        strcpy(data_, s);
    }


    Text(const Text& other) {
        const size_t len = strlen(other.data_);
        data_ = new char[len + 1];
        strcpy(data_, other.data_);
    }


    Text& operator=(const Text& other) {
        if (this == &other) return *this;
        const size_t len = strlen(other.data_);
        char* fresh = new char[len + 1];
        strcpy(fresh, other.data_);
        delete[] data_;
        data_ = fresh;
        return *this;
    }


    ~Text() {
        delete[] data_;
    }


    void setFirst(char ch) {
        if (data_[0] != '\0') data_[0] = ch;
    }


    const char* c_str() const {
        return data_;
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    string a, b;
    cin >> a >> b;
    Text x(a.c_str());
    Text y(x);
    Text z(b.c_str());
    y.setFirst('X');
    z = x;
    z.setFirst('Y');


    cout << x.c_str() << '\n';
    cout << y.c_str() << '\n';
    cout << z.c_str() << '\n';
    cout << x.c_str() << '\n';
    return 0;
}
```

## 第二题：虚继承与多态输出

 

### 题目描述

 

定义如下继承关系：

```text
          Base
         /    \
      Left   Right
         \    /
          Final
```

要求 Left 和 Right 虚继承 Base；Base::print() 为虚函数；Base 有虚析构函数；Final 重写 print()；通过 Base 指针创建并调用 Final 对象。

 

### 输入格式

 

输入一个整数 x，1 <= x <= 10^9。

 

### 输出格式

 

输出 Final x。

 

### 测试用例

 

输入：

```text
42
```

输出：

```text
Final 42
```

### 题解方法

 

虚继承解决菱形继承中 Base 子对象重复的问题；虚函数保证通过 Base 指针调用时发生动态绑定；虚析构保证 delete 基类指针时正确执行派生类析构。

 

### 完整 C++ 代码

```cpp
#include <iostream>
using namespace std;


class Base {
protected:
    int value_;
public:
    explicit Base(int value) : value_(value) {}
    virtual void print() const {
        cout << "Base " << value_ << '\n';
    }
    virtual ~Base() = default;
};


class Left : virtual public Base {
public:
    explicit Left(int value) : Base(value) {}
    void print() const override {
        cout << "Left " << value_ << '\n';
    }
};


class Right : virtual public Base {
public:
    explicit Right(int value) : Base(value) {}
    void print() const override {
        cout << "Right " << value_ << '\n';
    }
};


class Final : public Left, public Right {
public:
    explicit Final(int value)
        : Base(value), Left(value), Right(value) {}
    void print() const override {
        cout << "Final " << value_ << '\n';
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int x;
    cin >> x;
    Base* ptr = new Final(x);
    ptr->print();
    delete ptr;
    return 0;
}
```

## 第三题：网格挖矿与有序链表

 

### 题目描述

 

给定 n x m 的矿区，每个格子是非负整数，0 表示没有矿石。对每个非零连通块进行四方向 DFS，访问过的格子设为 0。

 

若矿石价值严格大于 threshold，则将其 value、row、column 插入按 value 升序排列的单链表。坐标从 0 开始。完成搜索后，删除链表中所有价值等于 target 的节点，并输出删除前后的链表。

 

### 输入格式

```text
n m threshold
接下来 n 行，每行 m 个整数
target
```

1 <= n,m <= 100。

 

### 输出格式

 

第一行输出删除前节点数 k，接下来 k 行输出 value row column。然后输出删除后节点数及对应节点，格式相同。

 

### 测试用例

 

输入：

```text
3 3 4
1 6 0
8 2 5
0 7 3
6
```

输出：

```text
4
5 1 2
6 0 1
7 2 1
8 1 0
3
5 1 2
7 2 1
8 1 0
```

### 题解方法

 

进入 DFS 时立即将格子置零，保证每个格子只访问一次。插入和删除都使用虚拟头节点，统一处理头节点和中间节点。DFS 为 O(nm)，链表插入最坏 O(k²)。

 

### 完整 C++ 代码

```cpp
#include <vector>
using namespace std;


struct Node {
    int value, row, col;
    Node* next;
    Node(int v, int r, int c) : value(v), row(r), col(c), next(nullptr) {}
};


int n, m, thresholdValue;
vector<vector<int>> grid;
Node* head = nullptr;
const int dr[4] = {-1, 1, 0, 0};
const int dc[4] = {0, 0, -1, 1};


void insertSorted(int value, int row, int col) {
    Node dummy(0, -1, -1);
    dummy.next = head;
    Node* prev = &dummy;
    while (prev->next != nullptr && prev->next->value < value) {
        prev = prev->next;
    }
    Node* node = new Node(value, row, col);
    node->next = prev->next;
    prev->next = node;
    head = dummy.next;
}


void dfs(int r, int c) {
    if (r < 0 || r >= n || c < 0 || c >= m || grid[r][c] == 0) {
        return;
    }
    const int value = grid[r][c];
    grid[r][c] = 0;
    if (value > thresholdValue) insertSorted(value, r, c);
    for (int d = 0; d < 4; ++d) dfs(r + dr[d], c + dc[d]);
}


Node* deleteAll(Node* first, int target) {
    Node dummy(0, -1, -1);
    dummy.next = first;
    Node* prev = &dummy;
    while (prev->next != nullptr) {
        if (prev->next->value == target) {
            Node* doomed = prev->next;
            prev->next = doomed->next;
            delete doomed;
        } else {
            prev = prev->next;
        }
    }
    return dummy.next;
}


int countNodes(Node* first) {
    int count = 0;
    for (Node* p = first; p != nullptr; p = p->next) ++count;
    return count;
}


void printList(Node* first) {
    for (Node* p = first; p != nullptr; p = p->next) {
        cout << p->value << ' ' << p->row << ' ' << p->col << '\n';
    }
}


void freeList(Node* first) {
    while (first != nullptr) {
        Node* next = first->next;
        delete first;
        first = next;
    }
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    cin >> n >> m >> thresholdValue;
    grid.assign(n, vector<int>(m));
    for (auto& row : grid) {
        for (int& value : row) cin >> value;
    }
    for (int r = 0; r < n; ++r) {
        for (int c = 0; c < m; ++c) {
            if (grid[r][c] != 0) dfs(r, c);
        }
    }


    cout << countNodes(head) << '\n';
    printList(head);
    int target;
    cin >> target;
    head = deleteAll(head, target);
    cout << countNodes(head) << '\n';
    printList(head);
    freeList(head);
    return 0;
```

## 第四题：链表两两交换与区间翻转

 

### 题目描述

 

给定一个单链表，先将节点两两交换，再将交换后链表的第 left 到第 right 个节点反转。节点位置从 1 开始。两两交换只修改节点指针，不允许只交换节点中的数值。

 

### 输入格式

```text
n
a1 a2 ... an
left right
```

1 <= n <= 10^5，1 <= left <= right <= n。

 

### 输出格式

 

输出最终链表，元素之间用一个空格分隔。

 

### 测试用例

 

输入：

```text
5
1 2 3 4 5
2 4
```

输出：

```text
2 4 3 1 5
```

### 题解方法

 

使用虚拟头节点。swapPairs 每次处理 prev、first、second；reverseBetween 先移动到 left 前一个节点，再使用头插法反转区间。时间复杂度 O(n)，空间复杂度 O(1)。

 

### 完整 C++ 代码

```cpp
#include <iostream>
using namespace std;


struct ListNode {
    int value;
    ListNode* next;
    explicit ListNode(int v) : value(v), next(nullptr) {}
};


ListNode* swapPairs(ListNode* head) {
    ListNode dummy(0);
    dummy.next = head;
    ListNode* prev = &dummy;
    while (prev->next != nullptr && prev->next->next != nullptr) {
        ListNode* first = prev->next;
        ListNode* second = first->next;
        first->next = second->next;
        second->next = first;
        prev->next = second;
        prev = first;
    }
    return dummy.next;
}


ListNode* reverseBetween(ListNode* head, int left, int right) {
    if (head == nullptr || left == right) return head;
    ListNode dummy(0);
    dummy.next = head;
    ListNode* before = &dummy;
    for (int pos = 1; pos < left; ++pos) before = before->next;
    ListNode* first = before->next;
    for (int i = 0; i < right - left; ++i) {
        ListNode* moved = first->next;
        first->next = moved->next;
        moved->next = before->next;
        before->next = moved;
    }
    return dummy.next;
}


void freeList(ListNode* head) {
    while (head != nullptr) {
        ListNode* next = head->next;
        delete head;
        head = next;
    }
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    ListNode dummy(0);
    ListNode* tail = &dummy;
    for (int i = 0; i < n; ++i) {
        int value;
        cin >> value;
        tail->next = new ListNode(value);
        tail = tail->next;
    }


    int left, right;
    cin >> left >> right;
    ListNode* head = swapPairs(dummy.next);
    head = reverseBetween(head, left, right);


    bool first = true;
    for (ListNode* p = head; p != nullptr; p = p->next) {
        if (!first) cout << ' ';
        first = false;
        cout << p->value;
    }
    cout << '\n';
    freeList(head);
    return 0;
}
```

## 第五题：相对名次

 

### 题目描述

 

给定 n 名运动员的互不相同的成绩。成绩越大名次越靠前。第一、第二、第三名分别输出 Gold Medal、Silver Medal、Bronze Medal，其余输出具体名次。输出顺序必须与输入运动员顺序一致。

 

### 输入格式

```text
n
s1 s2 ... sn
```

### 输出格式

 

输出 n 个结果，使用一个空格分隔。

 

### 测试用例

 

输入：

```text
5
10 3 8 9 4
```

输出：

```text
Gold Medal 5 Bronze Medal Silver Medal 4
```

### 题解方法

 

复制成绩数组并降序排序，用哈希表记录成绩到排名字符串的映射，最后遍历原数组输出。复杂度 O(n log n)。

 

### 完整 C++ 代码

```cpp
#include <algorithm>
#include <iostream>
#include <string>
#include <unordered_map>
#include <vector>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int n;
    cin >> n;
    vector<int> score(n), sortedScore;
    for (int& value : score) cin >> value;
    sortedScore = score;
    sort(sortedScore.rbegin(), sortedScore.rend());


    unordered_map<int, string> rankOf;
    for (int i = 0; i < n; ++i) {
        if (i == 0) rankOf[sortedScore[i]] = "Gold Medal";
        else if (i == 1) rankOf[sortedScore[i]] = "Silver Medal";
        else if (i == 2) rankOf[sortedScore[i]] = "Bronze Medal";
        else rankOf[sortedScore[i]] = to_string(i + 1);
    }


    for (int i = 0; i < n; ++i) {
        if (i > 0) cout << ' ';
        cout << rankOf[score[i]];
    }
    cout << '\n';
    return 0;
}
```

## 第六题：曼哈顿距离最小生成树

 

### 题目描述

 

给定平面上的 n 个点，任意两点之间都可以连线，边权为两点的曼哈顿距离 |x1-x2| + |y1-y2|。求使所有点连通的最小总边权。

 

### 输入格式

 

第一行输入 n，接下来 n 行输入点坐标 xi yi。1 <= n <= 1000。

 

### 输出格式

 

输出最小总边权。

 

### 测试用例

 

输入：

```text
3
0 0
2 0
0 3
```

输出：

```text
5
```

### 题解方法

 

这是完全图，使用 O(n²) Prim，不显式保存全部边。维护每个未加入点到当前生成树的最短距离，每次选择最小者加入并更新。

 

### 完整 C++ 代码

```cpp
#include <climits>
#include <cstdlib>
#include <iostream>
#include <utility>
#include <vector>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n;
    cin >> n;
    vector<pair<long long, long long>> point(n);
    for (auto& [x, y] : point) cin >> x >> y;


    const long long INF = LLONG_MAX / 4;
    vector<long long> best(n, INF);
    vector<bool> used(n, false);
    best[0] = 0;
    long long answer = 0;


    for (int step = 0; step < n; ++step) {
        int u = -1;
        for (int v = 0; v < n; ++v) {
            if (!used[v] && (u == -1 || best[v] < best[u])) u = v;
        }
        used[u] = true;
        answer += best[u];


        for (int v = 0; v < n; ++v) {
            if (used[v]) continue;
            long long distance =
                llabs(point[u].first - point[v].first) +
                llabs(point[u].second - point[v].second);
            best[v] = min(best[v], distance);
        }
    }


    cout << answer << '\n';
    return 0;
}
```

## 第七题：相邻不同的队列

 

### 题目描述

 

给定 n 个整数，是否可以重新排列，使任意相邻两个整数都不相同？若可以，同时输出一种合法排列。

 

### 输入格式

```text
n
a1 a2 ... an
```

### 输出格式

 

若不存在，输出 No。若存在，第一行输出 Yes，第二行输出一种合法排列。存在多种方案时输出任意一种。

 

### 测试用例

 

输入：

```text
6
1 1 1 2 2 3
```

一种合法输出：

```text
Yes
1 2 1 3 2 1
```

### 题解方法

 

最大出现次数为 mx。存在合法排列的充要条件是 mx <= (n+1)/2。构造时使用最大堆，每次取剩余次数最多的元素；用一个暂存项保存上一次选择且尚有剩余次数的元素，从而保证相邻不同。

 

### 完整 C++ 代码

```cpp
#include <algorithm>
#include <iostream>
#include <queue>
#include <unordered_map>
#include <utility>
#include <vector>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n;
    cin >> n;
    unordered_map<int, int> frequency;
    int maximum = 0;
    for (int i = 0; i < n; ++i) {
        int value;
        cin >> value;
        maximum = max(maximum, ++frequency[value]);
    }


    if (maximum > (n + 1) / 2) {
        cout << "No\n";
        return 0;
    }


    priority_queue<pair<int, int>> heap;
    for (const auto& [value, count] : frequency) {
        heap.push({count, value});
    }


    vector<int> answer;
    pair<int, int> previous = {0, 0};


    while (!heap.empty()) {
        auto current = heap.top();
        heap.pop();
        answer.push_back(current.second);
        --current.first;
        if (previous.first > 0) heap.push(previous);
        previous = current;
    }


    cout << "Yes\n";
    for (int i = 0; i < n; ++i) {
        if (i > 0) cout << ' ';
        cout << answer[i];
    }
    cout << '\n';
    return 0;
}
```

## 第八题：最大段式回文

 

### 题目描述

 

将字符串切分成若干连续非空段 P1,P2,...,Pk，要求 Pi == P(k-i+1)，求最大的 k。

 

### 输入格式

 

输入一个只含小写字母的字符串 s，长度不超过 5000。

 

### 输出格式

 

输出最大段数 k。

 

### 测试用例

 

输入：

```text
abcfguyfgabc
```

输出：

```text
5
```

### 题解方法

 

从左右两端同时扫描，分别累积左段和右段。当两段相等时立即切下，答案加 2；最后剩余的中间部分贡献 1。贪心地选择最短相同外层段，可以为内部保留最多的继续分段机会。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <string>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    string s;
    cin >> s;
    int left = 0;
    int right = static_cast<int>(s.size()) - 1;
    string leftPart, rightPart;
    int answer = 0;


    while (left < right) {
        leftPart.push_back(s[left++]);
        rightPart = s[right--] + rightPart;
        if (leftPart == rightPart) {
            answer += 2;
            leftPart.clear();
            rightPart.clear();
        }
    }


    if (left == right || !leftPart.empty()) ++answer;
    cout << answer << '\n';
    return 0;
}
```

## 第九题：道路最大能见度

 

### 题目描述

 

有向图中每条边有一个能见度 w。从城市 1 到城市 n 的一条路径的质量定义为路径上所有边权的最小值。求所有路径中质量的最大值。若不存在路径，输出 T\_T。

 

### 输入格式

 

第一行输入 n m，接下来 m 行输入 u v w，表示有向边 u 到 v。

 

### 输出格式

 

输出最大瓶颈值；无路时输出 T\_T。

 

### 测试用例

 

输入：

```text
4 5
1 2 8
1 3 5
2 4 3
3 4 4
2 3 7
```

输出：

```text
4
```

### 题解方法

 

定义 best\[v\] 为从 1 到 v 的最大瓶颈值。经过边 u 到 v 后，候选值为 min(best\[u\], w)；若候选值更大则更新。使用最大堆，每次扩展当前瓶颈最大的状态。

 

### 完整 C++ 代码

```cpp
#include <climits>
#include <iostream>
#include <queue>
#include <utility>
#include <vector>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n, m;
    cin >> n >> m;
    vector<vector<pair<int, int>>> graph(n + 1);
    for (int i = 0; i < m; ++i) {
        int u, v, w;
        cin >> u >> v >> w;
        graph[u].push_back({v, w});
    }


    vector<int> best(n + 1, -1);
    priority_queue<pair<int, int>> heap;
    best[1] = INT_MAX;
    heap.push({best[1], 1});


    while (!heap.empty()) {
        auto [capacity, u] = heap.top();
        heap.pop();
        if (capacity != best[u]) continue;
        for (auto [v, weight] : graph[u]) {
            int candidate = min(capacity, weight);
            if (candidate > best[v]) {
                best[v] = candidate;
                heap.push({candidate, v});
            }
        }
    }


    if (best[n] == -1) cout << "T_T\n";
    else cout << best[n] << '\n';
    return 0;
}
```

## 第十题：括号染色

 

### 题目描述

 

给定一个完全匹配的括号串。每个括号可以染成 0（不染色）、1（红色）、2（蓝色）。

 

约束：

 
1. 每一对匹配括号中，必须恰好一个括号不染色，另一个染红或蓝；
 
2. 相邻的两个括号不能染成相同的非零颜色；
 
3. 两个相邻括号都不染色是允许的。
 

求合法染色方案数，对 1000000007 取模。

 

### 输入格式

 

输入一个长度不超过 700 的合法括号串。

 

### 输出格式

 

输出方案数。

 

### 测试用例

 

输入：

```text
(())
```

输出：

```text
12
```

### 题解方法

 

先用栈求每个左括号对应的右括号位置。定义 dp\[l\]\[r\]\[a\]\[b\]：区间 \[l,r\] 左端颜色为 a、右端颜色为 b 的方案数。

 
- 若 match\[l\] == r，区间是外层括号包裹的内部区间；
 
- 否则区间由 \[l,match\[l\]\] 与 \[match\[l\]+1,r\] 两段拼接；
 
- 合并时只检查相邻边界颜色是否合法。
 

### 完整 C++ 代码

```cpp
using namespace std;


const long long MOD = 1000000007LL;


struct Matrix {
    long long value[3][3]{};
};


string s;
vector<int> matchPos;
vector<vector<Matrix>> memo;
vector<vector<bool>> visited;


bool validAdjacent(int leftColor, int rightColor) {
    if (leftColor == 0 && rightColor == 0) return true;
    return leftColor != rightColor;
}


Matrix solveInterval(int left, int right) {
    if (visited[left][right]) return memo[left][right];
    visited[left][right] = true;
    Matrix result;


    if (left + 1 == right) {
        result.value[0][1] = 1;
        result.value[0][2] = 1;
        result.value[1][0] = 1;
        result.value[2][0] = 1;
        return memo[left][right] = result;
    }


    if (matchPos[left] == right) {
        Matrix inner = solveInterval(left + 1, right - 1);
        const int pairColor[4][2] = {
            {0, 1}, {0, 2}, {1, 0}, {2, 0}
        };
        for (const auto& colors : pairColor) {
            int outerLeft = colors[0];
            int outerRight = colors[1];
            for (int innerLeft = 0; innerLeft < 3; ++innerLeft) {
                for (int innerRight = 0; innerRight < 3; ++innerRight) {
                    if (validAdjacent(outerLeft, innerLeft) &&
                        validAdjacent(innerRight, outerRight)) {
                        result.value[outerLeft][outerRight] =
                            (result.value[outerLeft][outerRight] +
                             inner.value[innerLeft][innerRight]) % MOD;
                    }
                }
            }
        }
    } else {
        int middle = matchPos[left];
        Matrix first = solveInterval(left, middle);
        Matrix second = solveInterval(middle + 1, right);
        for (int a = 0; a < 3; ++a) {
            for (int b = 0; b < 3; ++b) {
                for (int c = 0; c < 3; ++c) {
                    for (int d = 0; d < 3; ++d) {
                        if (validAdjacent(b, c)) {
                            result.value[a][d] =
                                (result.value[a][d] +
                                 first.value[a][b] * second.value[c][d]) % MOD;
                        }
                    }
                }
            }
        }
    }
    return memo[left][right] = result;
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    cin >> s;
    int n = static_cast<int>(s.size());
    matchPos.assign(n, -1);
    stack<int> st;
    for (int i = 0; i < n; ++i) {
        if (s[i] == '(') st.push(i);
        else {
            int left = st.top();
            st.pop();
            matchPos[left] = i;
        }
    }


    memo.assign(n, vector<Matrix>(n));
    visited.assign(n, vector<bool>(n, false));
    Matrix answer = solveInterval(0, n - 1);


    long long total = 0;
    for (int i = 0; i < 3; ++i) {
        for (int j = 0; j < 3; ++j) {
            total = (total + answer.value[i][j]) % MOD;
        }
```
