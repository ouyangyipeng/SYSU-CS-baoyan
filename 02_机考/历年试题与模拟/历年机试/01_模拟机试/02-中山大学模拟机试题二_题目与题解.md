# 中山大学模拟机试题二_题目与题解
## 第一题：动态数组的深拷贝与删除

 

### 题目描述

 

实现 DynamicArray 类，内部只能使用 int 指针保存数组。要求实现构造函数、拷贝构造函数、拷贝赋值运算符、析构函数、size、removeAll 和 print。

 

removeAll(x) 删除所有等于 x 的元素，并将剩余元素保存在一块大小恰好的新动态内存中。

 

### 输入格式

 

第一行输入 n。第二行输入 n 个整数。第三行输入待删除整数 x。

 

### 输出格式

 

先输出原对象的长度和内容，再输出深拷贝对象删除后的长度和内容，共四行。

 

### 测试用例

 

输入：

```text
4
1 3 3 5
3
```

输出：

```text
4
1 3 3 5
2
1 5
```

### 题解方法

 

拷贝构造和赋值运算必须重新申请内存。removeAll 先统计保留元素个数，再申请新数组并复制，最后释放旧数组。原对象与副本应互不影响。

 

### 完整 C++ 代码

```cpp
#include <algorithm>
#include <iostream>
using namespace std;


class DynamicArray {
private:
    int* data_;
    int size_;


public:
    DynamicArray() : data_(nullptr), size_(0) {}


    explicit DynamicArray(int n)
        : data_(n > 0 ? new int[n] : nullptr), size_(n) {}


    DynamicArray(const DynamicArray& other)
        : data_(other.size_ > 0 ? new int[other.size_] : nullptr),
          size_(other.size_) {
        if (size_ > 0) copy(other.data_, other.data_ + size_, data_);
    }


    DynamicArray& operator=(const DynamicArray& other) {
        if (this == &other) return *this;
        int* fresh = other.size_ > 0 ? new int[other.size_] : nullptr;
        if (other.size_ > 0) {
            copy(other.data_, other.data_ + other.size_, fresh);
        }
        delete[] data_;
        data_ = fresh;
        size_ = other.size_;
        return *this;
    }


    ~DynamicArray() {
        delete[] data_;
    }


    int size() const {
        return size_;
    }


    int& operator[](int index) {
        return data_[index];
    }


    void removeAll(int target) {
        int newSize = 0;
        for (int i = 0; i < size_; ++i) {
            if (data_[i] != target) ++newSize;
        }


        int* fresh = newSize > 0 ? new int[newSize] : nullptr;
        int position = 0;
        for (int i = 0; i < size_; ++i) {
            if (data_[i] != target) fresh[position++] = data_[i];
        }


        delete[] data_;
        data_ = fresh;
        size_ = newSize;
    }


    void print() const {
        for (int i = 0; i < size_; ++i) {
            if (i > 0) cout << ' ';
            cout << data_[i];
        }
        cout << '\n';
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n;
    cin >> n;
    DynamicArray original(n);
    for (int i = 0; i < n; ++i) cin >> original[i];


    int target;
    cin >> target;
    DynamicArray copied(original);
    copied.removeAll(target);


    cout << original.size() << '\n';
    original.print();
    cout << copied.size() << '\n';
    copied.print();
    return 0;
}
```

## 第二题：动物园多态

 

### 题目描述

 

动物园中有狗和猫。狗叫声为 W，类型为 0；猫叫声为 M，类型为 1。

 

请设计抽象基类 Animal，以及 Dog 和 Cat 两个派生类。程序先按输入顺序输出所有动物叫声，再输出所有狗的叫声，最后输出所有猫的叫声。必须通过 Animal 指针调用虚函数。

 

### 输入格式

 

第一行输入 n。第二行输入 n 个整数，0 表示狗，1 表示猫。

 

### 输出格式

 

第一行按原顺序输出叫声；第二行输出所有狗叫声；第三行输出所有猫叫声。字符之间不加空格。

 

### 测试用例

 

输入：

```text
4
0 1 1 0
```

输出：

```text
WMMW
WW
MM
```

### 题解方法

 

在 Animal 中把 shout 和 type 声明为纯虚函数，并声明虚析构函数。使用 vector 保存 Animal 指针，调用时发生运行时多态，最后逐个 delete。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;


class Animal {
public:
    virtual char shout() const = 0;
    virtual int type() const = 0;
    virtual ~Animal() = default;
};


class Dog : public Animal {
public:
    char shout() const override {
        return 'W';
    }
    int type() const override {
        return 0;
    }
};


class Cat : public Animal {
public:
    char shout() const override {
        return 'M';
    }
    int type() const override {
        return 1;
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n;
    cin >> n;
    vector<Animal*> animals;
    for (int i = 0; i < n; ++i) {
        int type;
        cin >> type;
        if (type == 0) animals.push_back(new Dog);
        else animals.push_back(new Cat);
    }


    for (const Animal* animal : animals) cout << animal->shout();
    cout << '\n';
    for (const Animal* animal : animals) {
        if (animal->type() == 0) cout << animal->shout();
    }
    cout << '\n';
    for (const Animal* animal : animals) {
        if (animal->type() == 1) cout << animal->shout();
    }
    cout << '\n';


    for (Animal* animal : animals) delete animal;
    return 0;
}
```

## 第三题：多继承构造顺序

 

### 题目描述

 

设计类 BaseB、DerivedB1、DerivedB2、BaseA、DerivedA 和 FinalClass。

 

DerivedB1 与 DerivedB2 虚继承 BaseB；DerivedA 普通继承 BaseA；FinalClass 按顺序继承 DerivedB2、DerivedB1、DerivedA。每个构造函数输出“类名 编号”。

 

### 输入格式

 

输入一个整数 id。

 

### 输出格式

 

构造一个 FinalClass 对象，输出实际构造顺序。

 

### 测试用例

 

输入：

```text
7
```

输出：

```text
BaseB 7
DerivedB2 7
DerivedB1 7
BaseA 7
DerivedA 7
FinalClass 7
```

### 题解方法

 

虚基类最先构造，而且只构造一次；非虚基类按 FinalClass 继承列表的声明顺序构造。DerivedA 构造前先构造自己的普通基类 BaseA。

 

### 完整 C++ 代码

```cpp
#include <iostream>
using namespace std;


class BaseB {
public:
    explicit BaseB(int id) {
        cout << "BaseB " << id << '\n';
    }
};


class DerivedB1 : virtual public BaseB {
public:
    explicit DerivedB1(int id) : BaseB(id) {
        cout << "DerivedB1 " << id << '\n';
    }
};


class DerivedB2 : virtual public BaseB {
public:
    explicit DerivedB2(int id) : BaseB(id) {
        cout << "DerivedB2 " << id << '\n';
    }
};


class BaseA {
public:
    explicit BaseA(int id) {
        cout << "BaseA " << id << '\n';
    }
};


class DerivedA : public BaseA {
public:
    explicit DerivedA(int id) : BaseA(id) {
        cout << "DerivedA " << id << '\n';
    }
};


class FinalClass : public DerivedB2, public DerivedB1, public DerivedA {
public:
    explicit FinalClass(int id)
        : BaseB(id), DerivedB2(id), DerivedB1(id), DerivedA(id) {
        cout << "FinalClass " << id << '\n';
    }
};


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    int id;
    cin >> id;
    FinalClass object(id);
    return 0;
}
```

## 第四题：ELFHash 链地址表

 

### 题目描述

 

实现一个固定大小为 m 的哈希表，必须使用 ELFHash，并使用链地址法解决冲突。每个桶中的字符串按插入顺序保存。

 

操作：

 
- 0 s：插入字符串 s。若已存在输出 existed，否则输出 insert ok；
 
- 1 s：查询字符串 s。若存在，输出它插入时的冲突次数，即它在桶中的下标；否则输出 -1。
 

### 输入格式

 

第一行输入操作数 n 和哈希表大小 m，接下来 n 行输入 op 和字符串 s。

 

### 输出格式

 

每个操作输出一行结果。

 

### 测试用例

 

输入：

```text
8 10
0 a
0 k
0 u
0 k
1 a
1 k
1 u
1 b
```

输出：

```text
insert ok
insert ok
insert ok
existed
0
1
2
-1
```

### 题解方法

 

计算 ELFHash(s) % m 得到桶下标。用 vector 模拟每个桶的链表，并在线性扫描桶时得到元素位置。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;


unsigned ELFHash(const char* str) {
    unsigned h = 0;
    unsigned g;
    while (*str != '\0') {
        h = (h << 4) + static_cast<unsigned char>(*str++);
        g = h & 0xf0000000U;
        if (g != 0) h ^= g >> 24;
        h &= ~g;
    }
    return h;
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n, m;
    cin >> n >> m;
    vector<vector<string>> table(m);


    while (n--) {
        int operation;
        string s;
        cin >> operation >> s;
        int bucket = static_cast<int>(ELFHash(s.c_str()) % m);
        int position = -1;
        for (int i = 0; i < static_cast<int>(table[bucket].size()); ++i) {
            if (table[bucket][i] == s) {
                position = i;
                break;
            }
        }


        if (operation == 0) {
            if (position != -1) {
                cout << "existed\n";
            } else {
                table[bucket].push_back(s);
                cout << "insert ok\n";
            }
        } else {
            cout << position << '\n';
        }
    }
    return 0;
}
```

## 第五题：字符串双向唯一映射

 

### 题目描述

 

给定两个等长字符串 A 和 B，判断是否存在字符间的双向唯一映射，使 A 中每个字符替换后恰好得到 B。

 

同一个 A 字符必须始终映射到同一个 B 字符，不同 A 字符不能映射到同一个 B 字符。

 

### 输入格式

 

第一行输入测试组数 T。每组输入两个不含空格的字符串 A 和 B。

 

### 输出格式

 

每组输出 Yes 或 No。

 

### 测试用例

 

输入：

```text
3
egg add
foo bar
paper title
```

输出：

```text
Yes
No
Yes
```

### 题解方法

 

维护 A 到 B 和 B 到 A 两张映射表。扫描每一对字符时，两张表都必须与已有映射一致。复杂度 O(|A|)。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <string>
#include <unordered_map>
using namespace std;


bool isomorphic(const string& a, const string& b) {
    if (a.size() != b.size()) return false;
    unordered_map<char, char> forward;
    unordered_map<char, char> backward;


    for (int i = 0; i < static_cast<int>(a.size()); ++i) {
        char x = a[i];
        char y = b[i];
        if (forward.count(x) != 0 && forward[x] != y) return false;
        if (backward.count(y) != 0 && backward[y] != x) return false;
        forward[x] = y;
        backward[y] = x;
    }
    return true;
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int tests;
    cin >> tests;
    while (tests--) {
        string a, b;
        cin >> a >> b;
        cout << (isomorphic(a, b) ? "Yes" : "No") << '\n';
    }
    return 0;
}
```

## 第六题：训练机器人

 

### 题目描述

 

给定一个 n 行 m 列迷宫，字符 X 表示障碍，点号表示空地，R 表示起点，T 表示终点。任意两个非障碍格子之间有且只有一条简单路径。

 

机器人沿唯一路径从 R 走到 T。到达某个格子时，若除来路外还有多于一个尚未走过的可走相邻格子，则该格子是分岔路口。求正确路径经过的分岔路口数。

 

### 输入格式

 

第一行输入测试组数 K。每组第一行输入 n m，接下来 n 行输入迷宫。

 

### 输出格式

 

每组输出一个整数。

 

### 测试用例

 

输入：

```text
2
2 3
T.R
.X.
3 3
...
XRX
..T
```

输出：

```text
1
2
```

### 题解方法

 

非障碍格子构成一棵树，因此递归时只需要排除父节点。每个节点先统计除父节点外的可走邻居数，若大于 1 则分岔数加一；然后继续 DFS，找到 T 后沿递归栈返回答案。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;


int n, m;
vector<string> maze;
const int dr[4] = {-1, 1, 0, 0};
const int dc[4] = {0, 0, -1, 1};


bool inside(int r, int c) {
    return r >= 0 && r < n && c >= 0 && c < m;
}


int dfs(int r, int c, int parentR, int parentC, int forks) {
    if (maze[r][c] == 'T') return forks;


    int choices = 0;
    for (int d = 0; d < 4; ++d) {
        int nr = r + dr[d];
        int nc = c + dc[d];
        if (!inside(nr, nc) || maze[nr][nc] == 'X') continue;
        if (nr == parentR && nc == parentC) continue;
        ++choices;
    }


    int nextForks = forks + (choices > 1 ? 1 : 0);
    for (int d = 0; d < 4; ++d) {
        int nr = r + dr[d];
        int nc = c + dc[d];
        if (!inside(nr, nc) || maze[nr][nc] == 'X') continue;
        if (nr == parentR && nc == parentC) continue;
        int result = dfs(nr, nc, r, c, nextForks);
        if (result != -1) return result;
    }
    return -1;
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int tests;
    cin >> tests;
    while (tests--) {
        cin >> n >> m;
        maze.resize(n);
        int startR = -1;
        int startC = -1;
        for (int r = 0; r < n; ++r) {
            cin >> maze[r];
            for (int c = 0; c < m; ++c) {
                if (maze[r][c] == 'R') {
                    startR = r;
                    startC = c;
                }
            }
        }
        cout << dfs(startR, startC, -1, -1, 0) << '\n';
    }
    return 0;
}
```

## 第七题：字典序最小拓扑序

 

### 题目描述

 

给定一个可能含重边的有向图。若图是 DAG，输出字典序最小的拓扑序；否则输出 It's not a DAG!。

 

### 输入格式

 

第一行输入测试组数 T。每组第一行输入 n m，接下来 m 行输入有向边 u v。顶点编号为 1 到 n。

 

### 输出格式

 

每组输出一行。拓扑序中数字用一个空格分隔，行末无多余空格。

 

### 测试用例

 

输入：

```text
2
5 5
1 2
1 3
2 4
3 4
4 5
3 3
1 2
2 3
3 1
```

输出：

```text
1 2 3 4 5
It's not a DAG!
```

### 题解方法

 

使用 Kahn 算法统计入度。为了得到字典序最小结果，把所有当前入度为 0 的点放入小根堆。最终输出节点数不足 n，说明存在有向环。

 

重边可以逐条保存，只要入度也逐条增加和减少即可。

 

### 完整 C++ 代码

```cpp
#include <functional>
#include <iostream>
#include <queue>
#include <vector>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int tests;
    cin >> tests;
    while (tests--) {
        int n, m;
        cin >> n >> m;
        vector<vector<int>> graph(n + 1);
        vector<int> indegree(n + 1, 0);


        for (int i = 0; i < m; ++i) {
            int u, v;
            cin >> u >> v;
            graph[u].push_back(v);
            ++indegree[v];
        }


        priority_queue<int, vector<int>, greater<int>> ready;
        for (int u = 1; u <= n; ++u) {
            if (indegree[u] == 0) ready.push(u);
        }


        vector<int> order;
        while (!ready.empty()) {
            int u = ready.top();
            ready.pop();
            order.push_back(u);
            for (int v : graph[u]) {
                if (--indegree[v] == 0) ready.push(v);
            }
        }


        if (static_cast<int>(order.size()) != n) {
            cout << "It's not a DAG!\n";
        } else {
            for (int i = 0; i < n; ++i) {
                if (i > 0) cout << ' ';
                cout << order[i];
            }
            cout << '\n';
        }
    }
    return 0;
}
```

## 第八题：双人楼层训练

 

### 题目描述

 

一栋楼有 H 层。第一位住户初始在 1 层，第二位住户初始在 H 层。每天每人都必须独立选择向下移动一层、原地不动或向上移动一层，但不能走出 1 到 H 层。

 

每天移动结束后，两人不能处于同一层。求恰好 D 天后，第一人位于 h1 层、第二人位于 h2 层的方案数。答案对 1000000007 取模。

 

### 输入格式

 

输入 H D h1 h2。约束为 2 <= H <= 50，0 <= D <= 50。

 

### 输出格式

 

输出方案数。

 

### 测试用例

 

输入：

```text
4 2 2 3
```

输出：

```text
4
```

### 题解方法

 

定义 dp\[day\]\[a\]\[b\] 为 day 天后两人分别在 a、b 层的方案数。枚举两人的九种移动组合，过滤越界和同层状态。使用滚动数组把空间降为 O(H²)，时间复杂度 O(DH²)。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <vector>
using namespace std;


const long long MOD = 1000000007LL;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int height, days, target1, target2;
    cin >> height >> days >> target1 >> target2;


    vector<vector<long long>> current(
        height + 1, vector<long long>(height + 1, 0));
    current[1][height] = 1;


    for (int day = 0; day < days; ++day) {
        vector<vector<long long>> next(
            height + 1, vector<long long>(height + 1, 0));


        for (int floor1 = 1; floor1 <= height; ++floor1) {
            for (int floor2 = 1; floor2 <= height; ++floor2) {
                if (current[floor1][floor2] == 0) continue;
                for (int move1 = -1; move1 <= 1; ++move1) {
                    for (int move2 = -1; move2 <= 1; ++move2) {
                        int next1 = floor1 + move1;
                        int next2 = floor2 + move2;
                        if (next1 < 1 || next1 > height) continue;
                        if (next2 < 1 || next2 > height) continue;
                        if (next1 == next2) continue;
                        next[next1][next2] =
                            (next[next1][next2] +
                             current[floor1][floor2]) % MOD;
                    }
                }
            }
        }
        current.swap(next);
    }


    cout << current[target1][target2] << '\n';
    return 0;
}
```

## 第九题：蜡烛照明

 

### 题目描述

 

给定一个网格：

 
- 点号表示空地；
 
- C 表示蜡烛；
 
- X 表示不透光障碍。
 

每支蜡烛会照亮所在行和列四个方向上的所有空地，光线遇到障碍 X 或网格边界时停止。蜡烛不会阻挡其他蜡烛的光。求未被照亮的空地数量。

 

### 输入格式

 

第一行输入 n m，接下来 n 行输入网格。1 <= n,m <= 500。

 

### 输出格式

 

输出未被照亮的空地数量。

 

### 测试用例

 

输入：

```text
3 5
..X..
.C...
..X.C
```

输出：

```text
3
```

### 题解方法

 

对每支蜡烛向四个方向扫描，遇到障碍或边界停止，经过空地时将 lit 标记为真。最后统计 grid 中仍未标记的点号。复杂度为 O(蜡烛数乘以 n+m)。

 

### 完整 C++ 代码

```cpp
#include <iostream>
#include <string>
#include <vector>
using namespace std;


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    int n, m;
    cin >> n >> m;
    vector<string> grid(n);
    for (string& row : grid) cin >> row;


    vector<vector<bool>> lit(n, vector<bool>(m, false));
    const int dr[4] = {-1, 1, 0, 0};
    const int dc[4] = {0, 0, -1, 1};


    for (int r = 0; r < n; ++r) {
        for (int c = 0; c < m; ++c) {
            if (grid[r][c] != 'C') continue;
            for (int d = 0; d < 4; ++d) {
                int nr = r + dr[d];
                int nc = c + dc[d];
                while (nr >= 0 && nr < n && nc >= 0 && nc < m &&
                       grid[nr][nc] != 'X') {
                    if (grid[nr][nc] == '.') lit[nr][nc] = true;
                    nr += dr[d];
                    nc += dc[d];
                }
            }
        }
    }


    int answer = 0;
    for (int r = 0; r < n; ++r) {
        for (int c = 0; c < m; ++c) {
            if (grid[r][c] == '.' && !lit[r][c]) ++answer;
        }
    }
    cout << answer << '\n';
    return 0;
}
```

## 第十题：不同的合法括号子序列

 

### 题目描述

 

给定一个只含左括号和右括号的字符串 S。删除若干字符后得到的字符串称为 S 的子序列。

 

求 S 中有多少个不同的非空子序列是合法括号序列。不同的删除位置若得到相同字符串，只计一次。答案对 1000000007 取模。

 

输入包含多组数据，以单独一行的 # 结束。

 

### 输入格式

 

每行一个括号字符串，长度为 1 到 100。最后一行为 #。

 

### 输出格式

 

每组输出一个整数。

 

### 测试用例

 

输入：

```text
()()
(()
)()((()))
#
```

输出：

```text
2
1
5
```

### 题解方法

 

普通子序列 DP 会把不同位置生成的同一字符串重复计数。预处理 next\[pos\]\[type\]，表示从 pos 开始第一个左括号或右括号的位置。

 

生成目标子序列时，每次只选择当前位置之后该字符的第一次出现。这样每个不同结果字符串只有一条规范生成路径。

 

定义 dfs(last,balance)：当前最后选择位置为 last，未匹配左括号数为 balance。balance 为 0 且已经选择过字符时，可以在此结束形成一个合法非空序列；随后尝试选择下一个左括号或在 balance 大于 0 时选择右括号。

 

### 完整 C++ 代码

```cpp
#include <cstring>
#include <iostream>
#include <string>
using namespace std;


const int MOD = 1000000007;


string s;
int nextPosition[105][2];
int memo[105][105];


int dfs(int last, int balance) {
    int& answer = memo[last + 1][balance];
    if (answer != -1) return answer;


    long long ways = 0;
    if (last != -1 && balance == 0) ways = 1;


    int nextOpen = nextPosition[last + 1][0];
    if (nextOpen != -1) {
        ways += dfs(nextOpen, balance + 1);
    }


    int nextClose = nextPosition[last + 1][1];
    if (balance > 0 && nextClose != -1) {
        ways += dfs(nextClose, balance - 1);
    }


    answer = static_cast<int>(ways % MOD);
    return answer;
}


int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);


    while (cin >> s && s != "#") {
        int n = static_cast<int>(s.size());
        int lastOpen = -1;
        int lastClose = -1;
        nextPosition[n][0] = -1;
        nextPosition[n][1] = -1;


        for (int i = n - 1; i >= 0; --i) {
            if (s[i] == '(') lastOpen = i;
            else lastClose = i;
            nextPosition[i][0] = lastOpen;
            nextPosition[i][1] = lastClose;
        }


        memset(memo, -1, sizeof(memo));
        cout << dfs(-1, 0) << '\n';
    }
    return 0;
}
```
