# 机考题型与练习索引

以下归纳来自历年备考总结，目的是帮助安排练习顺序。它不是一套还原试卷，也不包含付费题解全文。

| 题型 | 需要熟练的内容 | 自检方法 |
|---|---|---|
| 补全类与继承关系 | 构造顺序、初始化列表、虚函数、虚基类、虚析构 | 能解释每个构造和析构何时执行 |
| 拥有动态资源的类 | 深拷贝、自赋值、析构、赋值时资源释放 | 复制后修改一个对象不影响另一个，无重复释放 |
| 锁定主程序的接口题 | 参数、返回值、访问权限、命名与 const | 按给定调用方编译，不擅自修改接口 |
| 链表与指针 | 插入、删除、反转、区间操作 | 检查空链、单节点、首尾节点和指针更新顺序 |
| 字符串与哈希 | 字典序、映射、频次、重复模式 | 区分单向映射与双向一一对应，覆盖重复字符 |
| 搜索与连通性 | DFS、BFS、并查集、网格边界 | 防止重复访问；明确起点、终点和不可达情况 |
| 图论 | 拓扑排序、最短路、最小生成树 | 先判断有向/无向、是否有负边、求路径还是连接全部点 |
| 贪心 | 局部选择、排序、可行性判定 | 给出为什么局部选择不会丢掉最优解的理由 |
| 动态规划 | 状态、转移、初值、遍历顺序 | 明确状态所表示的集合，检查重复计数与取模 |

有的题对内存和指针行为有额外检查。只通过样例不代表正确，应主动测试边界、资源释放和接口限制。
