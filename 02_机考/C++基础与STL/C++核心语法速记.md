# C/C++ 核心语法

用于复习基础概念与口头简答。S 为优先掌握，A 为常见知识，B 为扩展内容；标记表示复习建议，不是出题概率统计。

## 指针与引用

### [S] 区别

- 指针可为空、可改指向，需要解引用；引用必须初始化，语义上是对象别名。
- `const T&` 不复制对象且不允许通过该引用修改对象，但并不意味着“被赋值对象的旧资源不能删除”。

## 深拷贝与 Rule of Three/Five

### [S] 深拷贝

- 类拥有堆资源时，拷贝构造要重新分配并复制内容；否则默认浅拷贝只复制指针，两个对象会重复释放。

### [S] Rule of Three

- 若类需要自定义析构函数、拷贝构造、拷贝赋值中的一个，通常三个都需要。
- C++11 后扩展为 Rule of Five：再加移动构造、移动赋值。

### [S] 拷贝赋值为什么要释放旧资源

- 左侧对象原来已拥有资源；更新资源指针时，若丢失旧指针而未释放对应资源，就会泄漏。
- `rhs` 是 `const&` 只保证不通过它修改右侧对象，删除的是 `this` 的旧资源。
- 应先成功分配并复制新资源，再替换和释放旧资源，避免分配失败后破坏原对象。正确处理自赋值，并优先使用 copy-and-swap 或 RAII 容器。

## 多态与虚函数

### [S] 动态多态

- 基类用 `virtual` 声明函数，通过基类指针/引用调用时，根据对象真实类型动态绑定。
- 值传递 `Base b = Derived{}` 会发生对象切片，派生部分丢失；`Base&`/`Base*` 不复制对象，所以保留动态类型。

### [S] 虚析构

- 多态基类析构函数应为 virtual；否则经基类指针 `delete` 派生对象会产生未定义行为/资源泄漏风险。

## 多继承与虚继承

### [S] 菱形继承

- B、C 都继承 A，D 再继承 B、C；普通继承会让 D 含两份 A。
- `virtual public A` 让最派生对象只保留一份共享 A 子对象。
- 虚基类由**最派生类**负责初始化，因此 B/C 构造函数里写的 A 初始化在构造 D 时会被忽略。

## 初始化列表

### [S] 冒号后的作用

```cpp
C::C(int x) : base(x), member(x), ptr(nullptr) {}
```

- 在进入构造函数体前直接构造成员/基类。
- `const` 成员、引用成员、无默认构造的成员需要初始化；未提供合适的类内默认成员初始化式时，应在初始化列表中指定。
- 先初始化虚基类，再按继承声明顺序初始化直接基类，最后按成员声明顺序初始化成员；不按列表书写顺序。

## static、friend、default、delete、explicit

### [A] 快答

- `static` 成员属于类整体，所有对象共享；静态成员函数没有 `this`。
- `friend` 授予函数或类访问私有成员的权限，不使其变成本类成员；友元关系不自动传递或继承。
- `= default` 要求编译器生成默认特殊成员函数。
- `= delete` 禁止某个操作，如禁止拷贝。
- `explicit` 可防止构造函数或转换函数参与不期望的隐式转换；显式直接初始化仍可使用。常见用途是避免单参数构造函数产生隐式转换。

## new/delete、C 字符串与内存函数

### [S] 配对

- `new T` ↔ `delete`；`new T[n]` ↔ `delete[]`。
- `malloc/free` 只分配字节，不调用 C++ 构造/析构；现代 C++ 优先 RAII、`vector`、`string`、智能指针。

### [A] `<cstring>`

- `strlen`：不含结尾 `\0` 的长度。
- `strcmp`：按字典序比较，不要用 `==` 比 C 字符串内容。
- `strcpy` 不检查目标容量，容易溢出；已知容量时也优先 `std::string`。
- `memcpy` 按字节复制，源/目标重叠时行为未定义；重叠用 `memmove`。
- `memset` 按字节填充，只适合 0、字节模式等，不能用它把 `int` 数组可靠设为任意整数。
