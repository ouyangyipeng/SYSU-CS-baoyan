# 头文件、STL 与输入输出

这份表用于复习标准 C++ 常见操作。考试允许的标准版本和头文件以当次环境为准；不要依赖非标准的万能头文件。

## 常用头文件

| 头文件 | 主要内容 | 常用操作 |
|---|---|---|
| `<iostream>` | `cin`、`cout` | 流式输入输出 |
| `<cstdio>` | `scanf`、`printf` | 格式化输入输出 |
| `<string>` | `std::string` | `size`、`empty`、`substr`、`find`、`getline` |
| `<vector>` | 动态数组 | `push_back`、`pop_back`、`size`、`resize`、`begin/end` |
| `<algorithm>` | 通用算法 | `sort`、`reverse`、`min/max`、`lower_bound`、`upper_bound`、`unique` |
| `<queue>` | 队列、优先队列 | `push`、`pop`、`front`、`top` |
| `<stack>` | 栈 | `push`、`pop`、`top` |
| `<deque>` | 双端队列 | `push_front/back`、`pop_front/back` |
| `<map>`、`<set>` | 有序映射与集合 | `insert`、`find`、`erase`、`lower_bound` |
| `<unordered_map>`、`<unordered_set>` | 哈希映射与集合 | 平均常数时间的查找、插入和删除 |
| `<utility>` | `pair`、移动与交换辅助 | `first`、`second`、`swap`、`move` |
| `<functional>` | 比较器 | `greater<T>`，用于小根堆等 |
| `<numeric>` | 数值算法 | `accumulate`、`iota`；C++17 起有 `gcd`、`lcm` |
| `<cstring>` | C 字符串与字节内存函数 | `strlen`、`strcmp`、`strcpy`、`memcpy`、`memmove`、`memset` |
| `<cmath>` | 常用数学函数 | `sqrt`、`abs`、`floor`、`ceil`、`pow` |
| `<limits>`、`<climits>` | 数值边界 | `numeric_limits<T>`、`INT_MAX` 等 |

## 操作里的易错点

- 栈、队列和堆的 `pop()` 只删除，不返回元素；先 `top()` 或 `front()`，再 `pop()`。
- `priority_queue<int>` 默认是大根堆；小根堆可用 `priority_queue<int, vector<int>, greater<int>>`。
- `vector::reserve(n)` 只预留容量，不能因此访问 `v[n-1]`；`resize(n)` 才改变元素数量。
- `sort` 需要严格弱序，比较器不能用 `<=` 替代 `<`。
- `lower_bound` 要求范围按同一比较规则有序，返回第一个不小于目标的位置；`upper_bound` 返回第一个大于目标的位置。
- `string::find` 未找到返回 `string::npos`，不要用 `> 0` 判断是否找到。
- `map[key]` 或 `unordered_map[key]` 在键不存在时会插入默认值；只判断存在性优先使用 `find`。
- `unique` 只把相邻重复项移到逻辑末尾，通常还需要 `erase`；一般去重前先排序。
- `accumulate(v.begin(), v.end(), 0LL)` 用 `long long` 累加，避免用 `0` 导致按 `int` 累加溢出。

## scanf 与 printf

`scanf` 需要变量地址，`printf` 需要变量值。格式与类型必须对应。

| 类型 | scanf | printf |
|---|---|---|
| `int` | `%d`，传 `&x` | `%d`，传 `x` |
| `long long` | `%lld` | `%lld` |
| `float` | `%f` | `%f`（可变参数中提升为 `double`） |
| `double` | `%lf` | `%f` |
| `char` | `%c` | `%c` |
| C 字符数组 | `%s`，传数组名 | `%s` |

- `scanf(" %c", &c)` 的格式前空格会跳过空白；`scanf("%c", &c)` 会读到换行等空白字符。
- 字符数组输入要限制宽度，例如 100 字节数组用 `%99s`，给结尾 `\0` 留空间。
- `scanf` 返回成功读入的项目数，循环读输入时应检查返回值。
- 使用 `getline` 读取整行时，注意前一次 `cin >>` 可能留下换行。
- 如果关闭了 C++ 流与 C 标准流的同步，尽量统一使用一种输入输出方式。
- 输出小数 `printf("%.2f", x)` 表示保留两位小数；它不会改变变量本身。
