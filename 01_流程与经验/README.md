# 流程与经验

## 先分清：出口资格与入口接收

广义上的保研是两个分别组织、分别评价的进程。即使本科和研究生都想留在中大计算机学院，也必须各自完成。

| 进程 | 出口：本科院校推荐资格 | 入口：目标院校研究生接收 |
|---|---|---|
| 解决的问题 | 本科院校是否推荐你免试读研 | 目标院校是否愿意接收你读研 |
| 比较范围 | 本科院校相应年级、专业或方向 | 全国申请者中进入相应类别复试的同学 |
| 核心结果 | 获得推免资格，或进入候补／专项等名单 | 通过接收考核，并进入对应学位类别的可接收范围 |
| 中大计算机主要看什么 | 学业成绩与规定加分形成的综合成绩、年度推荐名额 | 复试成绩、志愿与接收计划 |

两端都落实，通常意味着主要选拔关卡已通过，但正式录取仍需完成国家推免服务系统的报考及相关确认。只有「出口」没有「入口」，不代表目标学校一定接收；只有「入口」没有「出口」，也不能凭预推免成绩免试入学。

### 出口：中大计算机学院本科生如何取得资格

以下说明针对 2027 届，外校同学应查自己本科院校的推荐办法。

1. **确认基本条件。** 资格认定有课程、英语、体测、纪律等要求，先达到申请条件，再谈排序。
2. **按正确口径计算学业成绩。** 培养方案中的公必＋专必；有专业限选要求的方向还要计入相应限选课。学业成绩按细则折算成百分制后占 95%，不能直接拿全课程 GPA 代替。
3. **申请规定加分。** 特殊学术专长占 2%，只认指定竞赛、奖级与贡献条件，经材料审核、答辩及公示认定；不能把所有科研、论文和竞赛奖都当作加分。完整指标另有 3% 的在校期间参军入伍并退役项，具体按适用细则执行。
4. **查看排序和名额。** 通常先在专业／方向内按综合成绩排序，再依年度名额分配确定拟推荐和候补。追加名额、跨方向统筹等以当年通知为准，不能只拿往年保研率机械套算。
5. **区分专项。** 工程硕博士等专项不是分数不够就自动分配的保底，须另看申请条件、志愿、名额和相应限制。

常见加分误解：公示「学术专长分 80」不等于综合成绩加 80；在 2% 权重下对应增加 `80 × 0.02 = 1.6` 分。没有相应加分的项目按规则记零。

官方出处：[2027 届学术专长加分公示](https://cse.sysu.edu.cn/article/3617)、[2027 届拟推荐名单及候补公示](https://cse.sysu.edu.cn/article/3630)。具体课程、资格与指标范围应同时查看当年资格认定通知和最新学院遴选细则。

### 入口：全国申请者如何进入中大计算机学院

本仓库对应的 2026 年考核（2027 届入学）按预推免组织，不再套用旧夏令营流程。基本过程为：

1. 提交简历、介绍视频、成绩单等报名材料，完成线上综合测评，通过初审进入复试。
2. 参加机考。当年邮件明确机考不计入复试总分，仅作为面试参考；老师仍可能问到机考表现。
3. 参加面试：英文朗读翻译、自我介绍、评议组提问答辩。当年通常由 5 位老师组成评议组；具体顺序和计时有组间差异。
4. 按复试成绩、报考志愿及接收计划确定接收范围。当年硕士通知采用分数优先、先学硕后专硕的原则，直博另行排序；计算机与计算数学的排序也不能混为一张榜。

面试人数约 600—900 人是经验量级估计，不是官方固定人数。重要的是：**入口比较的是全国申请者，不是仅和自己本科年级比较；出口的绩点排名，也不会直接变成入口的面试排名。**

官方要求见[2027 年推免接收报名通知](https://cse.sysu.edu.cn/article/3587)。材料初审不是统考意义上的「初试」；预推免考核通过、进入可接收范围与国家系统正式待录取确认也是不同阶段。

### 保本院最容易混淆的几件事

- 「本科推免资格拿到了」不等于「本院研究生录取了」。
- 「预推免面试通过了」不等于「本科推免资格也有了」。
- 出口的普通类／工程硕博士专项，与入口的学硕／专硕不是同一组分类。
- 导师沟通、优营或预推免通过通知，不能代替国家系统操作。
- 资格认定和接收考核可以在时间上交错进行，不必等出口最终公示后才开始准备入口。
