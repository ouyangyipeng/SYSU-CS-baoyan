## 先看这几条

- **机试不能只刷算法。** 前两题集中考类、深拷贝、继承和内存管理；后八题涉及链表、枚举、栈、并查集、树、图和动态规划。
- **英语不只考论文。** 科普、企业新闻、产业报道和社会经济话题均有回忆。通常先读后译，老师可能只要求翻译少数句子。
- **项目和基础知识都要准备。** 有的考生几乎只被问项目，有的被集中问数学，也有人先问项目再补一道数学题。
- **提问深浅、是否被打断，不能直接推断成绩。** 「老师很友善」「压力面」「没怎么问」都只是个人体验。
