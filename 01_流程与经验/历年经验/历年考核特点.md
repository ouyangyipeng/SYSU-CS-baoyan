# 历年考核特点

这是对 2022—2025 年经验资料的概括，保留可用于复习的共同点，不转载付费经验稿全文或专有题解。

## 反复出现的内容

| 环节 | 常见内容 | 使用时的限制 |
|---|---|---|
| 机考语言 | C/C++ | 语言版本、允许的头文件按当年平台要求 |
| 机考前段 | 类与继承、多态、深拷贝、指针、锁定主函数后补接口 | 不代表每年都固定在相同题号 |
| 算法题 | 链表、字符串、哈希、图搜索、贪心、动态规划 | 题量和难度分布存在批次差异 |
| 英语 | 抽短文、朗读、翻译 | 也有更早批次或其他环节的英文问答记录，不能混用 |
| 自我介绍 | 数分钟 PPT | 具体时长由当次通知决定 |
| 自由追问 | 项目、个人贡献、数学和专业课 | 不同组差别明显，不能保证只问项目 |

## 看历年资料时先核对什么

1. 是夏令营、预推免还是统考复试。
2. 是计算机学院还是相关的其他学院。
3. 标题中的年份指考试时间还是入学届别。
4. 内容是正式通知、完整题面、考生回忆，还是整理者预测。
5. 分值、提交限制和面试时长是否来自同一批次。

一些资料对部分分构成的表述不同。练习时可以利用子任务分步完成，但不要默认某年的编译分、样例分和内存检查分在下一年原样保留。

## 如何用这些经验复习

先补稳 C++ 对象模型和内存，再练链表、字符串、搜索与图论；动态规划训练状态、转移和边界条件。面试则准备英文短文和真实项目解释，同时回顾能被材料引出的数学概念。
