# 操作系统面试题
1. 什么是操作系统? 有什么特点? 操作系统本质上是一个运行在计算机上的软件程序, 是管理和控制整个计算机系统软件和 硬件资源的管理者。操作系统把一些硬件功能封装成简单易用的服务，使用户方便的使用计 算机，无需关注底层原理，只需要对操作系统发出命令即可。 特点：并发、共享、虚拟、异步
 
2. 操作系统有哪些功能
 
- 处理机管理功能：作业和进程调度，进程控制和进程通信。
 
- 存储器管理功能：内存分配、地址映射、内存保护和内存扩充。
 
- 文件管理功能：文件存储空间的管理、文件操作的一般管理、目录管理、文件的读写管 理，存取控制和保护。
 
- 设备管理功能：缓冲区管理、设备分配、设备驱动和设备无关性（设备处理）。
 
3. 并发和并行有什么区别
 
- 并发：多个事件在同一时间间隔内发生，这些事件宏观上是同时发生的，微观上是交替 发生的
 
- 并行：多个事件在同一时刻同时发生
 
4. 什么是异步
 
- 多道程序环境下，允许多个程序并发执行，由于资源有限，是走走停停的，以不可预知的速 度向前推进。
 
- 例如进程 A 有 a1，a2 两条指令，进程 B 有 b1，b2 两条指令，它们并发执行时的顺序可能 是 a1，a2，b1，b2 或者 a1，b1，b2，a1 等等
 
5. 什么是内核态和用户态？为什么要分两个态？ 内核态和用户态是操作系统中的两种特权级别
 

为了保护系统的安全性和稳定性。通过限制用户态程序的权限，可以防止恶意代码对系统资 源的滥用和破坏。

 
- 内核态下，操作系统拥有对系统硬件和资源的完全控制权，可以执行特权指令和访问受 限资源，如底层硬件设备
 
- 用户态下，应用程序只能执行受限的指令集，无法直接访问底层硬件和系统资源，必须 通过操作系统提供的接口来进行操作。
 
6. 用户态和内核态是如何切换的 用户态切换到内核态的 3 种方式：
 
- 系统调用（Trap）：用户态进程 主动 要求切换到内核态的一种方式，主要是为了 使用内核态才能做的事情比如读取磁盘资源。
 
- 中断（Interrupt）：当外围设备完成用户请求的操作后(例如 IO 完成)，会向 CPU 发出相应的中断信号，这时 CPU 会转去执行与中断信号对应的处理程序
 
- 异常（Exception）：当 CPU 在执行运行在用户态下的程序时，发生了某些事先不可知 的异常，这时会触发由当前运行进程切换到处理此异常的内核相关程序中，也就转到了 内核态，比如缺页异常
 
7. 什么是系统调用 系统调用其实就是操作系统提供给应用程序的接口函数，应用程序可以通过这些接口函数来 让操作系统执行相关的操作，从而获得操作系统的服务
 
8. 程序和进程的区别程序：是静态的，就是个存放在磁盘里的可执行文件，如: QQ.ext 进程：是动态的，是程序的一次执行过程，如:可同时启动多个 QQ 程序
 
9. 进程状态的转换
 
- 创建状态(new)：进程正在被创建，尚未到就绪状态。
 
- 就绪状态(ready)：进程已处于准备运行状态，即进程获得了除了处理器之外的一切所需 资源，一旦得到处理器资源(处理器分配的时间片)即可运行。
 
- 运行状态(running)：进程正在处理器上运行(单核 CPU 下任意时刻只有一个进程处于 运行状态)。
 
- 阻塞状态(waiting)：又称为等待状态，进程正在等待某一事件而暂停运行如等待某资源 为可用或等待 IO 操作完成。即使处理器空闲，该进程也不能运行。
 
- 结束状态(terminated)：进程正在从系统中消失。可能是进程正常结束或其他原因中断退出运行。
 
10. 什么是进程调度？有哪些进程调度算法？在处于就绪态的进程里，按照一定的调度算法，选出一个进程并给它分配 CPU 时间让它运 行，从而实现多进程的并发执行。 先来先服务、短进程优先、时间片轮转、高相应比优先、优先级调度、多级反馈队列
 
11. 什么是多级反馈队列调度算法
 
- 设置多级就绪队列，优先级从高到低，时间片从小到大。
 
- 优先运行高优先级的进程，有多个进程处于最高优先级，则先来先服务
 
- 当一个进程运行完所在优先级的时间片，则被移动到下一级
 
- 新进程放入第一级队列
 
- 抢占式调度算法，如果有一个新的作业或进程进入系统并具有更高的优先级，则会抢占当前进程。
 
12. 什么是 CPU 利用率、周转时间、响应时间
 
- CPU 利用率 = CPU 工作时间 / 总时间
 
- 周转时间 = 作业提交时间到作业完成时间
 
- 带权周转时间 = 周转时间 / 服务时间
 
- 平均周转时间 = 作业周转总时间 / 作业个数
 
- 响应时间 = 从提交请求到系统响应这个请求的时间
 
- 吞吐量 = 单位时间内系统完成的作业数
 
13. 什么是进程同步和互斥
 
- 进程同步：并发导致了异步性，但有的进程之间需要遵循一定先后顺序，需要通过进程 同步实现。例如生产者和消费者问题。
 
- 进程互斥：一段时间内只允许一个进程使用的资源称为临界资源，为了保证一个时间段 内只允许一个进程访问该资源，需要通过进程互斥实现
 
14. 进程如何通信
 
- 共享存储：操作系统在内存中划出一块共享存储区，并映射到进程的虚拟地址空间，于是多 个进程可以访问相同的内存区域
 
- 消息队列：消息队列是指一个消息链表，发送进程将消息放入队列，接收进程从队列中获取 消息。消息队列可以实现消息的随机查询
 
- 管道通信：“管道”是指用于连接读写进程的一个共享文件，发送进程以字符流形式将大量 数据送入管道，接收进程可从管道接收数据。管道通信是先进先出的，不能实现随机读取。
 
15. 堆和栈有什么区别
 
- 堆是用于动态分配内存的一块区域，用于存储程序运行时动态创建的对象；堆的大小通 常较大，可以动态增长或缩小；多个线程可以共享堆内存；
 
- 栈由操作系统自动分配释放 ，用于存放函数的参数值、局部变量等；栈的大小通常较 小，具有固定的空间大小；每个线程通常拥有自己的独立栈空间
 
16. 什么是线程 线程是操作系统调度的最小执行单位，线程是进程中的⼀个执行单元。一个进程可以包含多 个线程，它们共享进程的资源(代码区、数据区、堆区)。但每个线程都有独立的程序计数器、 寄存器、栈
 
17. 线程和进程有什么区别
 
- 进程是资源分配的基本单位；线程是程序执行的基本单位。
 
- 进程拥有自己的资源空间，每启动一个进程，系统就会为它分配地址空间；而线程与 CPU 资源分配无关，多个线程共享同一进程内的资源，使用相同的地址空间。
 
- 线程之间的通信更方便，调度与切换比进程快很多，创建一个线程的开销小很多。
 
- 当一个线程崩溃时，会影响其他线程，导致整个进程终止。而进程相对独立，一个进程的崩溃不会影响其他进程。
 
18. 为什么要使用多线程
 
- 单核时代：如果一个任务需要执行耗时的操作（如网络请求、磁盘读写等），主线程会 被阻塞，导致整个程序无法响应其他事件。通过使用多线程，可以将耗时的操作放在一 个单独的线程中执行，使主线程保持响应。
 
- 多核时代：假如我们要计算一个复杂的任务，我们只用一个线程的话，不论系统有几个CPU 核心，都只会有一个 CPU 核心被利用到。而创建多个线程，这些线程可以被映 射到底层多个 CPU 上执行，提高任务执行效率
 
19. 锁是什么 锁本质上就是一块内存空间。当这个空间被赋值为 1 的时候表示加锁了，被赋值为 0 的时候 表示解锁了，仅此而已。多个线程抢一个锁，就是抢着要把这块内存赋值为 1
 
20. 自旋锁和互斥锁有什么区别主要区别在于等待锁释放时的不同处理方式：
 

互斥锁适用于临界区较长且持有时间较长的情况，而自旋锁适用于临界区较短且持有时间较短的情况。

 
- 自旋锁：自旋锁采用忙等待的方式。当一个线程尝试获取自旋锁时，如果锁已经被其他 线程持有，该线程会循环检查锁是否被释放。持续占用处理器资源
 
- 互斥锁：互斥锁采用阻塞等待的方式。当一个线程尝试获取互斥锁时，如果锁已经被其 他线程持有，该线程将被阻塞，直到锁被释放。不占用处理器资源。
 
21. 生产者消费者问题是什么？ 线程同步问题：有一个共享的缓冲区，用于存放生产者产生的数据。多个生产者线程并发地 将数据放入缓冲区，多个消费者线程并发地从缓冲区中取出数据。缓冲区有固定的容量，当 缓冲区满时，生产者线程必须等待；当缓冲区为空时，消费者线程必须等待。
 
22. 什么是信号量信号量本质上是一个非负的整数计数器，表示系统中某种资源的数量，用于控制公共资源的 访问。操作系统提供一对 PV 原语来操作信号量。
 
- P（Wait）操作：减少信号量的计数，如果计数变为负数，则线程被阻塞等待资源。如 果计数为正数或零，则线程可以继续执行。
 
- V（Signal）操作：增加信号量的计数，表示有一个资源可用。如果有线程正在等待资 源，则唤醒其中一个或多个线程。
 
23. 什么是死锁两个或多个并发的进程(线程)因为互相等待对方释放某些资源，而导致各进程都阻塞而无法 继续执行
 
24. 产生死锁的条件有哪些
 
- 互斥条件：进程所等待的资源是互斥使用的
 
- 不可抢占：进程所使用的资源在使用完之前不能被抢占
 
- 请求保持：进程已经持有了至少一个资源，请求的新资源被其他进程占有，且不释放已 有资源
 
- 循环等待：存在一种循环等待链
 
25. 预防死锁的方法有哪些
 
- 破坏不可抢占条件：进程所获得的新资源在得不到满足时，必须立即释放保持的所有资 源，待以后重更新申请缺点：造成前一阶段工作的失效
 
- 破坏请求保持条件：让进程在运行前就一次性申请它所需要的所有资源。缺点：资源利用率低
 
- 破坏循环等待条件：首先对系统中的资源编号，规定进程必须按编号递增的顺序请求资 源，请求低编号资源时要先释放高编号资源。缺点：编号困难，不利于新增资源
 
26. 避免死锁的方法有什么？什么是银行家算法？银行家算法是一个避免死锁的算法，系统在进行资源分配之前，模拟资源分配和回收的情况， 判断是否存在一种资源分配顺序可以保证所有进程都能够完成并释放资源，而不会发生死 锁。若存在才分配资源，否则等待。
 
27. 什么是动态重定位？有什么好处？这种方式就是在将逻辑地址转为物理地址推迟到了具体的程序运行时期，即当运行到该指令 再实时执行逻辑地址到物理地址的转换。 优点：允许程序在内存中发生移动；可将程序分配到不连续的存储区中；在程序运行前只需 装入它的部分代码即可投入运行
 
28. 内存空间扩充的方法有哪些？
 
- 覆盖技术：将程序分为多个段，常用的段常驻内存，不常用的段在需要时调入内存。缺 点是需要程序员手动分段。
 
- 交换技术：操作系统可以将某些进程暂时换出外存，把外存中已经具备运行条件的进程 换入内存
 
- 虚拟内存：每一个进程都有独立的虚拟地址空间，程序开始执行时，只有很快会用到部 分被装入内存，暂时用不到的留在外存。在每个进程看来，就像它自己独享了整个内存。
 
29. 内存连续分配有哪些方式
 
- 单一连续分配：内存中只能有一道用户程序，用户程序独占整个用户区空间
 
- 固定分区分配：这是将内存用户空间划分为若干个固定大小的区域，在每个分区中只装 入一个进程
 
- 动态分区分配：不会预先划分内存分区，而是在进程装入内存时根据进程的大小动态地 建立分区。可以使用空闲分区表或者空闲分区链记录空闲分区的情况。
 
30. 动态内存分区分配算法有哪些？
 
- 首次适应：从头到尾找合适的分区
 
- 最佳适应：优先使用更小的分区
 
- 最坏适应：优先使用更大的分区
 
- 临近适应：每次从上次查找结束的位置开始查找
 
31. 分页存储如何实现逻辑地址到物理地址的转换？
 
a. 确定逻辑地址 A 对应的页号 P，P=逻辑地址/页面长度。
 
b. 找到该页号在内存中对应的起始的地址。
 
c. 确定逻辑地址的页面偏移量 W，W=逻辑地址%页面长度。 逻辑地址=起始地址+页内偏移量
 
32. 分段存储和分页存储有什么区别？
 
- 段是信息的逻辑单位，它是根据用户的需要划分的；页是信息的物理单位，是为了管理 主存的方便而划分的；
 
- 段的大小不固定，由它所完成的功能决定；页大大小固定，由系统决定；
 
33. 什么是快表快表是访问速度比内存快得多的一种高速缓冲存储器。因为每次访问逻辑地址，就会查询页 表中的内存，经常访问到的页表项就可以放入快表中，加快访问速度。 空间局部性：如果程序访问了某个存储单元，那么不久之后其附近的存储单元很有可能再次 访问
 
34. 分页存储的地址变换过程
 
a. 算页号、页内偏移量
 
b. 检查页号合法性
 
c. 查快表，若命中则可知存放页面的内存块号，转到 5。若未命中，转到
 
d. 查页表，找到存放页面的内存块号，并将页表项复制到快表中。
 
e. 根据内存块号和页内偏移量计算物理地址
 
f. 访问目标存储单元
 
35. 页面置换算法有哪些
 
- 最佳置换算法：优先淘汰最长时间内不会被访问的页面，无法实现
 
- 先进先出置换算法：优先淘汰最先进入内存的页面
 
- 最近最久未使用算法：优先淘汰最近最久没访问的页面
 
- LRU(Least recently used)：优先淘汰掉最久未使用（即最老）的一条数据
 
- LFU(Least-frequently used)：优先淘汰掉过去被访问次数最少的一条数据。
 
36. 什么是抖动(颠簸)现象 页面频繁换入和换出的调度行为称为抖动，产生抖动的原因是进程频繁访问的页面数目高于 可用的物理块数。
 
37. 什么是缓冲区？有什么作用？ 高速设备与低速设备的不匹配，势必会让高速设备花时间等待低速设备。缓冲区（Buffer） 是指在内存中预留的一块区域，用于临时存储数据。用于解决 CPU 和 IO 速度不匹配的问 题。 例如：使用打印机打印文档，由于打印机的打印速度相对较慢，我们先把文档输出到打印机 相应的缓冲区，打印机再自行逐步打印，这时 CPU 可以处理别的事情。
 
38. 软链接和硬链接有什么区别
 
- 硬链接：在 Linux/类 Unix 文件系统中，每个文件和目录都有一个唯一的索引节点 （inode）号，用来标识该文件或目录。硬链接通过 inode 节点号建立连接，硬链接和 源文件的 inode 节点号相同，两者对文件系统来说是完全平等的（可以看作是互为硬 链接，源头是同一份文件），删除其中任何一个对另外一个没有影响，可以通过给文件 设置硬链接文件来防止重要文件被误删。
 
- 软链接：软链接是一个特殊的文件，其中包含指向目标文件或目录的路径，源文件删除 后，就无法通过软链接访问了
 
39. 磁盘调度算法有哪些？
 
- 先来先服务算法(First-Come First-Served，FCFS)：按照请求到达磁盘调度器的顺序进行 处理，先到达的请求的先被服务。
 
- 最短寻道时间优先算法(Shortest Seek Time First，SSTF)：优先选择距离当前磁头位置最 近的请求进行服务。可能会出现饥饿问题。
 
- 扫描算法(SCAN)：基本思想和电梯非常类似。磁头沿着一个方向扫描磁盘，如果经过 的磁道有请求就处理，直到到达磁盘的边界，然后改变移动方向，依此往复。
 
- 边扫描边观察算法(LOOK)：SCAN 算法中磁头到了磁盘的边界才改变移动方向，这样 可能会做很多无用功，LOOK 算法中如果磁头移动方向上已经没有别的请求，就可以立 即改变磁头移动方向。
