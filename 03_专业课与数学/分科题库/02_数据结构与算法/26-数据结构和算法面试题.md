# 数据结构和算法面试题
1. 数组和链表有什么区别？
 
- 物理存储结构不同：数组是顺序存储结构，用一组地址连续的存储单元来存储表中的元 素。链表是链式存储结构，不要求逻辑上相邻的两个元素在物理位置上也相邻，链表元 素除了存储元素本身的数据外，还需要存储一个指向下一个元素的位置数据，程序可以 通过该信息访问到下一个元素。
 
- 内存分配方式不同：数组的存储空间一般采用静态分配，在分配之前需要确定数组的 大小，申请的内存区域一般在栈区。链表的存储空间一般采用动态分配，内存申请单 位一般为一个链表节点的空间，链表的长度可以动态扩展，申请的内存区域一般在堆 区。
 
- 元素存取方式不同：数组是顺序存储结构，数组元素可以直接通过元素的下标进行直 接存取，时间复杂度为 O(1)。链表在进行元素存取时，需要遍历链表，时间复杂度为 O(n)
 
- 元素的插入和删除方式不同：数组在进行元素插入和删除时，需要移动数组内的元 素，时间复杂度为 O(n)；链表在进行元素插入和删除时无需移动链表内的元素，但由 于链表不是顺序存储结构，为寻找第 i 个元素，仍然需要遍历链表，因此时间复杂度 为 O(n)。
 
2. 栈和队列有什么异同点？它们有哪些应用(生活和计算机中)
 
- 相同点：逻辑结构都是线性结构；存储结构都可以用顺序存储或链式存储实现。
 
- 不同点：栈是后进先出，只允许在一端插入和删除数据；队列是先进先出，允许在一段 插入数据，另一端删除数据
 
- 栈的应用：实现递归；用于计算后缀表达式的值；编译原理中进行词法分析，移入操作 是入栈，规约是出栈；
 
- 队列的应用：进程调度当进程被创建完成后变为就绪状态，加入就绪队列。当进程请求 某一资源（如外设）的使用或等待某一事件的发生（如 I/O 操作的完成）时，它就从运 行态转换为阻塞态，根据阻塞原因的不同会设置多个阻塞队列。

9. 什么是二叉平衡树(AVL)?为什么要引入 AVL 树？
 
- AVL 树是一种高度平衡的二叉搜索树，即任意节点的左子树和右子树高度之差都不超过 1。
 
- 二叉搜索树虽可以缩短查找的效率，但如果数据有序或接近有序二叉搜索树将退化为单支 树，查找元素相当于在顺序表中搜索元素，效率低下。因此，当向二叉搜索树中插入新结 点后，如果能保证每个结点的左右子树高度之差的绝对值不超过 1(需要对树中的结点进行 调整)，即可降低树的高度，从而减少平均搜索长度。
 
10. 什么是红黑树？有哪些性质？红黑树，是一种二叉搜索树，但在每个结点上增加一个存储位表示结点的颜色，可以是 Red 或 Black。 通过任何一条从根到叶子的路径上各个结点着色方式的限制，红黑树确保 没有一条路径会比其他路径长出俩倍，因而是接近平衡的。 性质： (1) 每个结点不是红色就是黑色 (2) 根节点是黑色的 (3) 如果一个节点是红色的，则它的两个孩子结点是黑色的 (4) 对于每个结点，从该结点到其所有后代叶结点的简单路径上，均包含相同数目的黑色 结点 (5) 每个叶子结点都是黑色的(此处的叶子结点指的是空结点)
 
11. 为什么满足了上述性质，就能保证没有一条路径会比其他路径长出俩倍根据性质四，所有路径的黑色结点数量相同，则最短路径为全黑结点，而根据性质三，最 长路径就是红黑两结点交替
 
12. AVL 树和红黑树相比有区别
 
- 平衡度不同：AVL 树的平衡度比红黑树更严格，因为它要求左右子树的高度差不能超 过 1，而红黑树的平衡度要求比较宽松，只需要保证最长路径不超过最短路径的两倍 即可。
 
- 查询性能不同：AVL 树查询比红黑树略快，但复杂度都是 O(log n)，其中 n 是树中节 点的数量
 
- 插入和删除操作的性能不同：由于 AVL 树的平衡要求更严格，所以在进行插入和删除 操作时，可能需要进行更多的旋转操作来保持平衡，因此 AVL 树的插入和删除操作比 红黑树慢。
 
13. 红黑树有哪些应用
 
- C++ 的 STL 中，map 和 set 是用红黑树实现的
 
- Java 的集合框架(HashMap、TreeMap、TreeSet)； HashMap 的底层实现，在 JDK1.8 中为了解决过度哈希冲突带来的长链表，当链表长度大于某个阈值会将链表转为红黑 树；
 
- linux 内核中：CFS 进程调度算法中，vruntime 利用红黑树来进行存储，选择最小 vruntime 节点调度。
 
14. 什么是 B 树？为什么要使用 B 树？ B 树是一种多叉平衡查找树 B 树的设计目的是在外存储器（磁盘等）中快速查找数据。在外存储器中查找数据的速度 比在内存中查找要慢得多，因此 B 树被设计为可以最小化 I/O 次数，从而提高检索效率。
 
15. 什么是 B+树？B+树（B+ tree）是一种基于 B 树的数据结构，也是一种多叉树。与 B 树不同的是，B+树 的内部节点不存储数据，只存储索引，所有的数据都存储在叶子节点上。同时，B+树的叶 子节点都被链接在一起，形成一个有序链表，方便范围查找和遍历操作。
 
16. B 树和 B+树有什么区别
 
- B+树内部节点不存储数据，而是只存储索引，这可以使得每个节点可以存储更多的索 引，减少树的高度，降低磁盘 I/O 次数，提高查询效率。千万级的数据只需要三层的 B+树。
 
- B+树可以更好地支持范围查找和排序操作，因为叶子节点形成了有序链表，查询时只 需要遍历这个链表即可。

18. 如何构造哈夫曼树 哈夫曼树的构建过程是通过将权重最小的两个节点合并成一个新节点，并将其权重设为这 两个节点权重的和。不断重复这个过程，直到最终只剩下一个根节点为止构造出的哈夫曼树不唯一，但是他们的 WPL 一定相同
 
19. 什么是哈夫曼编码
 
- 哈夫曼编码是一种基于字符出现频率的可变长度编码，前缀编码方式。主要用于数据压缩 和传输。
 
- 哈夫曼编码的基本思想是：将出现频率高的字符用短的编码表示，出现频率低的字符用长 的编码表示。这样，编码后的字符串长度会变短，从而达到压缩数据的效果。
 
- 哈夫曼编码的实现需要进行以下步骤： 1. 统计每个字符在待编码文本中出现的频率。 2. 将每个字符及其出现频率作为叶子节点，构建一棵哈夫曼树。 3. 对于哈夫曼树上的每个叶子节点，规定向左走表示编码为 0，向右走表示编码为 1，将 其编码表示为从根节点到该叶子节点路径上的所有 0 和 1 的序列。
 
20. 什么是堆堆是一种特殊的树状数据结构，它满足以下两个主要性质：
 
- (二叉)堆是一个完全二叉树：意味着除了最底层外，其他层的节点都被填满，并且最 底层从左到右填充。
 
- 堆的每个节点都满足堆属性：对于大根堆来说，父节点的值大于或等于其子节点的 值；对于小根堆来说，父节点的值小于或等于其子节点的值。
 
21. 什么是深度优先搜索和广度优先搜索
 
- 深度优先搜索：对每一个可能的分支路径深入到不能再深入为止，而且每个结点只能 访问一次。使用递归实现
 
- 广度优先搜索：从上往下对每一层依次访问，在每一层中，从左往右（也可以从右往 左）访问结点，访问完一层就进入下一层，直到没有结点可以访问为止。使用队列实现。
 
22. 什么是最小生成树
 
- 生成树是针对无向图的，最小生成树是针对带权无向图的
 
- 生成树：一个有 n 个顶点的连通图的生成树是一个极小连通子图，它含有图中全部顶 点，但只包含构成一棵树的 n-1 条边。
 
- 最小生成树：带权连通图可能有多课生成树，权值之和最小的生成树称为最小生成树。
 
23. 求最小生成树有哪些算法？Kruskal 算法 将图中的所有边按边权值升序排序，依次选取各条边，若选取的边未使生成树形成回路， 则该边为最小生成树的一条边。 Prim 算法将图中所有顶点分为两个集合 U 和 V-U，初始时 U 中仅包含一个顶点，每次连接取两个顶 点集之间的最小边作为最小生成树的一条边，将该边位于 V-U 中的顶点移入 U，再重复操 作，直到 U 中包括 n 个顶点。
 
24. 最短路算法有哪些 Dijkstra 算法 Dijkstra 算法是一种求解无负权图中的单源最短路算法。它基于贪心策略，每次从起点开始 选择当前最短路径，并标记已访问的节点。然后，它更新与这些节点相邻的节点的距离， 并选择下一个最短的路径，直到到达目标节点为止。时间复杂度为 O(n^2)，堆优化之后为 O(nlogn) Floyd 算法 Floyd 算法是一种求解多源最短路的算法。它的基本思想是利用动态规划的思想，通过中 间节点的遍历来更新两个节点之间的最短路径。Floyd 算法采用一个二维数组来记录图中 所有节点对之间的最短距离，通过对这个数组不断更新，最终得到所有节点对之间的最短 路径。
 
25. 为什么 Dijkstra 算法不能处理负权边 因此 Dijkstra 算法是基于贪心策略，每次都找一个距源点 A 最近的点 B，就可以确定 A 到 B 的最短距离了。但是如果存在负权边，可能先通过并不是距源点最近的一个次优点，再 通过一个负权边，使得路径之和更小。

27. 什么是 AOE 网 在图论中，AOE 网（Activity On Edge Network）是一种用于表示工程项目或生产流程的有向 图。它的节点表示事件，边表示活动，边权表示完成活动所需的时间。 AOE 网可以预计整个工程的完工时间，并找出影响工程进度的"关键活动"，作为决策者提供 修改各活动预计进度的依据。关键活动是指不存在富裕时间的活动，即活动的最早开始时间 等于活动的最晚开始时间，关键活动如果不能按期完成会导致整个工程发送拖延。

29. 什么是欧拉图/半欧拉图？
 
- 欧拉回路：通过图中每条边恰好一次的回路
 
- 欧拉通路：通过图中每条边恰好一次的通路
 
- 欧拉图：具有欧拉回路的图
 
- 半欧拉图：有欧拉通路，无欧拉回路
 
30. 如何判断欧拉图/半欧拉图？
 
- 无向欧拉图：连通且无奇度顶点
 
- 无向半欧拉图：连通且恰好有两个奇度顶点
 
- 有向欧拉图：连通且所有点入度等于出度
 
- 有向半欧拉图：连通且恰好有两个奇度顶点，且一个是出度=入度+1，一个是入读=出 度+1

33. 什么是 P/NP/NPC/NPH 问题
 
- P 问题：能在多项式时间内解决的问题。
 
- NP 问题：NP 问题是指可以在多项式的时间里验证一个解的问题。
 
- Reduce：一个问题 A 可以约化为问题 B 的含义即是，可以用问题 B 的解法解决问题 A。
 
- NP-Complete 问题：是一个 NP 问题，并且所有的 NP 问题都可以约化到它。
 
- NP-Hard 问题：即所有的 NP 问题都能约化到它，但是他不一定是一个 NP 问题。

35. 什么是排序算法的稳定性 序列中两个相同的数字在排序前后位置顺序未改变。
 
36. 冒泡排序 冒泡排序是一种比较排序算法，其基本思想是通过比较相邻的元素并交换位置，从而把较 大的元素逐渐“冒泡”到数组的末尾，而较小的元素则逐渐“沉淀”到数组的前面。
 
37. 快速排序 快速排序是一种比较排序算法，采用分治的思想，先选取一个基准元素，将数组分成两个 子数组，其中一个子数组中的所有元素都小于基准元素，另一个子数组中的所有元素都大 于基准元素。然后，对两个子数组分别递归地进行快速排序，最终得到有序数组。 最好时间复杂度 O(nlogn)，每一次划分都将数组分为长度相等的两半。 最坏时间复杂度 O(n^2)，每一次划分都将数组划分为长度为 1 和 n-1 的两半
 
38. 直接插入排序 直接插入排序是一种简单直观的排序算法，其基本思想是将待排序的元素逐个插入到已排 序序列中的适当位置，从而得到一个新的有序序列。直接插入排序将待排序序列分为已排 序和未排序两个部分，初始时已排序部分只包含第一个元素，然后将未排序部分中的每个 元素插入到已排序部分的适当位置中。
 
39. 希尔排序 希尔排序是把记录按下标的一定增量分组，对每组使用直接插入排序算法排序；随着增量 逐渐减少，每组包含的关键词越来越多，当增量减至 1 时，整个文件恰被分成一组，算法 便终止
 
40. 简单选择排序 简单选择排序是一种选择排序算法，它的基本思想是每次从未排序的数据中选出最小的数 据，然后将其放到已排序数据的末尾。通过不断重复这个过程，直到所有数据都排好序为 止。
 
41. 堆排序堆排序分为两个阶段，以使用大根堆进行升序排序为例：
 
a. 建堆：将待排序序列看作是一棵完全二叉树，从最后一个非叶子节点开始，对每个节点 进行一次下滤（也就是将其与其子节点进行比较，如果不满足大根堆的性质则进行交换）， 直到根节点。
 
b. 排序：将堆顶元素（最大元素）与堆底元素交换，然后将堆的大小减 1，然后对堆顶元 素进行一次下滤。重复执行直到堆的大小为 1。 建堆步骤的时间复杂度O(n)，排序步骤的时间复杂度为 O(nlogn)，整体时间复杂度为 O(nlogn)
 
42. 归并排序 归并排序是一种经典的基于分治思想的排序算法。归并排序分为两个阶段，第一阶段是分 治阶段，将待排序序列不断二分，直到分成单个元素，这些单个元素可以看作是已经排好 序的子序列。第二阶段是合并阶段，将已经排好序的子序列两两合并成一个有序的序列， 直到整个序列有序。 将归并排序的过程表示为一棵递归树，假设待排序序列长度为 n，递归树的深度为 log₂n， 每层的时间复杂度为 O(n)，则归并排序的时间复杂度为 O(nlogn)
 
43. 桶排序 桶排序是一种线性排序算法，其基本思想是将待排序数据分割成若干个有序的桶，每个桶 内的元素再进行排序，最后将各个桶中的元素有序地合并起来，以达到排序的目的。 设元素个数为 n，桶数为 m，均匀分布时每个桶中的元素个数为 n/m。则时间复杂度为 O(n)+O(m\*n/m log(n/m) = O(n+k)
 
44. 基数排序 基数排序是一种非比较排序算法，基本思想是：将所有待比较数值统一为同样的数位长 度，数位较短的数前面补零。然后，从最低位开始，依次按每一位排序。这样从最低位排 序一直到最高位排序完成以后, 数列就变成一个有序序列。 时间复杂度 O(n\*k)，其中 k 为最大数的位数，空间复杂度为 O(n)
 
45. 简述 KMP 算法思想 在暴力匹配中，每趟匹配失败都是模式后移一位再从头开始比较，效率较低。KMP 算法可 以利用已经匹配过的信息，避免不必要的回溯。如果已匹配相等的前缀序列中有某个后缀 正好是模式的前缀，那么就可以将模式向后滑动到与这些相等字符对齐的位置开始比较
 
46. 什么是哈希表 哈希表又称为散列表，是根据关键字的值直接进行访问的数据结构，即它通过把关键码的 值映射到表中的一个位置以加快查找速度，其中映射函数叫做散列函数，存放记录的数组 叫做散列表。
 
47. 什么是装填因子 哈希表中已经存储的键值对数量与哈希表容量的比值。
 
48. 什么是哈希冲突 哈希表中不同的键经过哈希函数计算后映射到了相同的位置
 
49. 什么是算法的时间复杂度 算法的时间复杂度是衡量算法执行时间随输入规模增长而变化的量度。通常用大 O 符号（O） 来表示算法的时间复杂度
 
50. 什么是分治算法 分治算法的核心思想是将大问题分解为小问题，将问题分解为更小规模的子问题，直到可以 直接解决或者达到递归的终止条件。然后，递归地解决这些子问题，获得子问题的解。最后， 通过合并子问题的解，得到原问题的解。 经典应用：归并排序
 
51. 什么是动态规划算法 动态规划算法通过将问题划分为一系列重叠的子问题，并以自底向上的方式逐步求解这些子 问题，最终得到原问题的最优解。 经典应用：背包问题
 
52. 什么是贪心算法 贪心算法每次选择当前看起来最优的选择，而不考虑整体的最优解，以期望最终能够达到全 局最优解。 经典应用：零钱找零问题
 
53. 动态规划算法和分治算法有什么异同？分治和动态规划的共同点是它们都通过将问题划分为子问题，并根据子问题的解构建原问 题的解 不同点:
 
- 分治算法将问题划分为互不相交的子问题，每个子问题都是独立求解的，且子问题之 间不存在重叠。而动态规划算法将问题划分为重叠的子问题，子问题之间具有重叠 性，即子问题之间可能会多次计算相同的部分。
 
- 分治算法是通过递归，自顶向下求解。而动态规划算法则采用自底向上的方式，先解 决较小的子问题，然后逐步推导得到更大子问题的解
