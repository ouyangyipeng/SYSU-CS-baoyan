# 计算机组成与体系结构

用于复习基础概念与口头简答。S 为优先掌握，A 为常见知识，B 为扩展内容；标记表示复习建议，不是出题概率统计。

## Cache 与局部性

### [S] 局部性

- 时间局部性：刚访问的数据可能再次访问。
- 空间局部性：相邻地址可能很快访问。
- Cache line 是传输与一致性的基本块。

### [A] Cache 映射

- 直接映射：每块只有一个位置，快但冲突多。
- 全相联：任意位置，命中判断贵。
- 组相联：折中。

### [A] 写策略

- Write-through：同时写下级，简单但流量大。
- Write-back：先写 cache，替换时回写，需要 dirty bit。

## 流水线

### [A] 三类冒险

- 结构冒险：硬件资源冲突。
- 数据冒险：指令依赖，如 RAW。
- 控制冒险：分支导致下一条不确定。
- 解决：资源复制、forwarding/stall、分支预测与推测执行。

## CPU、GPU、NPU

### [S] 区别

- CPU：少量复杂核心，强调低延迟与通用控制。
- GPU：大量并行执行单元，适合规则、高吞吐数据并行。
- NPU：针对张量算子、低精度和数据流优化，能效高但编程/算子约束更强。
