# 计算机网络

用于复习基础概念与口头简答。S 为优先掌握，A 为常见知识，B 为扩展内容；标记表示复习建议，不是出题概率统计。

## TCP 与 UDP

### [S] 区别

- TCP：面向连接、可靠字节流、有序、流量/拥塞控制。
- UDP：无连接、尽力而为、保留报文边界、开销小。
- “UDP 更快”取决于场景；可靠性需要应用层自己补。

### [S] 三次握手

1. Client 发 SYN；2. Server 回 SYN+ACK；3. Client 回 ACK。
- 三次用于确认双方收发能力并同步初始序列号；两次无法充分避免旧连接请求等问题。

### [A] 四次挥手

- TCP 全双工，两方向关闭通常分别 FIN/ACK。
- 主动关闭方进入 TIME_WAIT，确保最后 ACK 可重传并让旧报文过期。

## 流量控制与拥塞控制

### [A] 区别

- 流量控制保护接收方，用接收窗口 rwnd。
- 拥塞控制保护网络，用拥塞窗口 cwnd；发送窗口受两者较小值约束。
- 经典机制：慢启动、拥塞避免、快重传、快恢复。

## HTTP/HTTPS

### [A] HTTP

- HTTP 是应用层协议；HTTP/1.1持久连接，HTTP/2多路复用，HTTP/3基于 QUIC/UDP。
- GET 通常用于读取且应幂等；POST 常用于提交，不保证幂等。

### [A] HTTPS

- HTTP over TLS；证书验证服务器身份，握手协商密钥，后续主要用对称加密传输。

## DNS

### [B] 过程

- 域名经递归/迭代查询解析为地址；本地、递归解析器和权威服务器会缓存，TTL 控制有效期。
