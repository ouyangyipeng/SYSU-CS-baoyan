# 机器学习与大模型基础

用于复习基础概念与口头简答。S 为优先掌握，A 为常见知识，B 为扩展内容；标记表示复习建议，不是出题概率统计。

## 训练、验证与测试

### [S] 三者区别

- 训练集拟合参数；验证集选模型/超参数；测试集只做最终无偏评估。
- 反复看测试集调参会造成测试集泄漏。

### [S] 过拟合

- 训练好、泛化差；可用更多数据、正则化、数据增强、早停、降低模型复杂度等缓解。
- 欠拟合是训练集都表现差。

## 常见损失与优化

### [A] 交叉熵

- 分类中衡量真实分布与预测分布差异；softmax + cross entropy 的梯度形式简洁。
- KL 散度不对称；交叉熵 $H(p,q)=H(p)+D_{KL}(p\|q)$。

### [A] Precision/Recall/F1

- Precision = TP/(TP+FP)，Recall = TP/(TP+FN)。
- F1 是二者调和平均；类别不平衡时比 accuracy 更有信息。

## Transformer 与 Self-Attention

### [S] 计算

$$Q=XW_Q,\quad K=XW_K,\quad V=XW_V$$
$$\operatorname{Attention}(Q,K,V)=\operatorname{softmax}\left(\frac{QK^T}{\sqrt{d_k}}\right)V$$

- 除以 $\sqrt{d_k}$ 防止点积随维度变大导致 softmax 饱和。
- Multi-head 让不同头学习不同子空间关系。

### [S] Transformer 结构

- Encoder：self-attention + FFN + residual + layer norm。
- Decoder：masked self-attention；在 encoder-decoder 架构中还有 cross-attention。
- GPT 类通常是 decoder-only。

### [S] 为什么捕捉长距离依赖

- 任意 token 一层内即可直接交互，路径长度短；RNN 需要沿序列逐步传递。
- 代价：标准 attention 时间/显存约 $O(n^2)$。

## CNN、RNN/LSTM 与 Transformer

### [A] 对比

- CNN 擅长局部模式与平移结构，归纳偏置强。
- RNN 顺序建模，LSTM用门控缓解长期依赖和梯度问题，但并行性差。
- Transformer全局交互、训练并行性好，但长序列成本高。

## DQN

### [A] 两个关键机制

- Experience Replay：随机采样过去经验，打破时间相关性、提高数据复用。
- Target Network：用延迟更新的目标网络计算 TD target，降低训练目标振荡。
- Double DQN 用在线网络选动作、目标网络估值，缓解过估计。

## 域适应与域泛化

### [A] 区别

- Domain Adaptation：训练时可以接触目标域数据（有标注或无标注）。
- Domain Generalization：训练时看不到目标域，只用多个源域学习可泛化表示。
- 不要把“目标域无标签”误说成“完全看不到目标域”。

## Benchmark、消融与统计

### [S] 三个概念

- Baseline：合理、可复现的对照方法。
- Ablation：移除/替换组件，验证性能来自哪里。
- 多次运行应报告均值、方差/置信区间；只报最好值容易误导。
