# Agent Systems 与安全

用于复习基础概念与口头简答。S 为优先掌握，A 为常见知识，B 为扩展内容；标记表示复习建议，不是出题概率统计。

## Agent、Workflow、Harness、Skill

### [S] 简洁区分

- Agent：模型围绕目标进行推理、工具调用和状态更新的系统主体。
- Workflow：预定义或半动态的步骤与控制流。
- Harness：围绕模型组织上下文、工具、控制、状态、约束与观测的运行环境。
- Skill：可复用的能力封装，包含说明、依赖、工具/代码和执行约束。

## 静态安全与运行时安全

### [S] 区别

- 静态：运行前检查权限、依赖、类型、控制流等，早发现、成本低，但看不到全部动态信息。
- 运行时：沙箱、鉴权、审计、限额、监控，能处理动态行为但有执行成本。
- 正确方案通常是两者组合。

## Agent 评估

### [S] 为什么难

- 输出开放、路径多样、外部工具变化、结果可能延迟出现；单一准确率无法覆盖质量、成本、延迟和风险。
- 生产评估需要任务成功、轨迹、资源、异常和用户反馈等多信号。

## 检索与 GraphRAG

### [A] RAG

- 先检索外部知识，再把证据提供给模型生成；减少参数内知识限制，但不能自动消除幻觉。
- 核心环节：切分、索引、召回、重排、上下文组织和引用验证。

### [A] GraphRAG

- 把实体/知识/技能及其关系显式建图，检索时利用语义和拓扑。
- 优势是关系与多跳路径；代价是构图质量、更新成本和推理开销。
