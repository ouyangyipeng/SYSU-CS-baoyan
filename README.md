# SYSU-CS-baoyan｜中山大学计算机保研资料

这里收集了准备中山大学计算机学院保研时用到的历年回忆题、机考题解、专业课与数学笔记、英语练习和面试材料模板，希望让后来的同学少花些找资料的时间。

**这是非官方资料汇编。** 当前整理到 2026 年考核（2027 届入学），同时保留此前年份的经验。回忆题可能存在遗漏，参考答案也可能有错；考试安排、评分和招生要求请以当年学院通知为准。

## 先分清：保研的「出口」和「入口」是两件事

广义上的「保研」其实包含**两个分别组织、分别评价的进程**。尤其是想保本院的同学，容易把它们当成一件事：

| | 出口：本科院校推荐资格 | 入口：目标院校研究生接收 |
|---|---|---|
| 要拿到什么 | 从本科毕业院校取得推免资格 | 通过想去的院校的优营／预推免考核，并进入可接收范围 |
| 与谁比较 | 本科院校内相应年级、专业或方向的同学 | 全国报名目标院校、通过初审并参加对应类别考核的同学 |
| 中大计算机的主要依据 | 按细则计算的学业成绩、学术专长等综合成绩及推荐名额 | 预推免复试成绩、报考志愿及接收计划 |

**出口决定「能不能被推荐出去」，入口决定「目标学校愿不愿意接收」。保本院也要分别完成这两件事。** 两端都落实，通常意味着主要选拔关卡已经通过，但还要按时完成国家推免服务系统的报考、复试和待录取确认，不能把预推免通过通知直接当成正式录取。

### 出口：取得本科推免资格

以下以**中山大学计算机学院 2027 届**为例，不是全国统一规则。

主要比较范围是本院相应专业／方向。学业部分按培养方案规定的**公必＋专必**计算；有专业限选要求的方向还要计入相应限选课，不能直接拿包含全部选修课的总 GPA 替代。按细则折算为百分制后，**学业成绩占 95%，指定竞赛的特殊学术专长成绩占 2%**。完整指标还包含 **3% 的在校期间参军入伍并退役项**；没有相应加分的项目按规则记零。

竞赛加分只认规定的赛事、奖级和贡献情况，需要申请并经审核，不是拿到任意国家级奖都能加。例如审核认定的学术专长项目分为 80 分时，计入综合成绩的是 `80 × 2% = 1.6` 分，不是总分直接加 80 分。

随后按综合成绩排序，结合当年学校下达的名额、专业分配和志愿确定普通类推荐与候补等名单。常说的「保研率划线」是对结果的概括，最终以名额和公示为准；工程硕博士等专项还有单独的申请条件和名额，不能简单理解成低于普通类分数线就自动获得的保底。

参考：[学术专长加分评定结果](https://cse.sysu.edu.cn/article/3617)、[拟推荐资格名单及候补公示](https://cse.sysu.edu.cn/article/3630)。完整课程、加分和专项要求请查当年资格认定通知及最新遴选细则。

### 入口：通过中大计算机学院预推免接收考核

这里仅讨论**申请进入中山大学计算机学院读研**。本仓库对应的 2026 年考核（2027 届入学）按预推免组织，不再按旧夏令营流程准备；后续年份仍需查看当年的接收通知。

比较对象不再只是本院同学，而是来自全国、通过初审并参加复试的申请者。参与面试者约 600—900 人属于经验量级估计，**不是官方公布的固定人数，也不是所有类别混在一起的一张榜**：计算机与计算数学、硕士与直博的排序口径需要区分。

基本流程是：

1. **报名与初审：** 提交简历、介绍视频及成绩单等材料，完成线上综合测评，筛选后进入复试。这不是统考意义上的「初试」。
2. **机考：** 先参加程序设计考试。当年考前邮件明确，机考分数不计入复试总分，只在面试时供老师参考。
3. **面试：** 英文短文朗读与翻译、自我介绍、评议组老师问答；当年现场反馈通常为 5 位老师，主要围绕材料、项目、专业基础或数学追问。
4. **排序与接收：** 按复试成绩和报考志愿，结合当年招生计划确定接收范围。当年硕士通知采用「分数优先、先学硕后专硕」的原则；学硕和专硕不是出口资格认定中的普通类与工程硕博士专项。

官方说明见[2027 年推免接收报名通知](https://cse.sysu.edu.cn/article/3587)，实际流程与组间差异见[现场流程与复盘](01_流程与经验/2026年（2027届）/现场流程与复盘.md)。两端的常见误区见[出口与入口说明](01_流程与经验/README.md)。

## 查找与使用

- 按上表选择复习主题；逐文件查找可看 [资料总目录](资料总目录.md)。
- Markdown 可直接阅读；PDF、Word、XMind 和 PPT 保留原格式，用对应软件打开。
- 先独立做题，再对照题解。复现代码时请检查边界条件、复杂度和内存管理，不把收录等同于已经通过完整评测。
- 英语模拟用于朗读与翻译训练，不作为考场原文；项目短答用于组织思路，不套用他人的经历。
