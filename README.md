# SYSU-CS-baoyan｜中山大学计算机保研资料

这里收集了准备中山大学计算机学院保研时用到的历年回忆题、机考题解、专业课与数学笔记、英语练习和面试材料模板，希望让后来的同学少花些找资料的时间。

**这是非官方资料汇编。** 当前整理到 2026 年考核（2027 届入学），同时保留此前年份的经验。回忆题可能存在遗漏，参考答案也可能有错；考试安排、评分和招生要求请以当年学院通知为准。

建议先看流程和题型，再补知识，最后做限时朗读与项目短答练习。

英语部分包含 **38 篇自编练习**：13 篇现场题材复原、15 篇同难度模拟、10 篇扩展题材。每篇都有英文与中文参考译文。复原只表示题材相近，不表示还原了试卷原文。

知识笔记以简要定义、性质和易错点为主；回答公式或复杂度时仍要交代假设。项目答辩部分提供组织回答的方法，不提供可照搬的个人经历。

## 查找与使用

- 按上表选择复习主题；逐文件查找可看 [资料总目录](资料总目录.md)。
- Markdown 可直接阅读；PDF、Word、XMind 和 PPT 保留原格式，用对应软件打开。
- 先独立做题，再对照题解。复现代码时请检查边界条件、复杂度和内存管理，不把收录等同于已经通过完整评测。
- 英语模拟用于朗读与翻译训练，不作为考场原文；项目短答用于组织思路，不套用他人的经历。

## 补充与勘误

欢迎通过 Issue 或 Pull Request 补充题目、修正答案。请注明考试年份、学院与批次，以及材料是官方发布、个人回忆还是模拟练习。涉及代码错误时，尽量附上最小反例和修正思路。

提交前请删除姓名、学号、联系方式、证件、报名账号和聊天截图中的个人信息，不上传尚未结束的考试内容。原作者署名、出处和使用说明应保留，具体见 [来源与使用说明](来源与使用说明.md)。
