# 领域适应与领域泛化

类型：同难度模拟。根据常见计算机英语题材自编的模拟练习，没有原题命中的含义。

## English

> A model trained on photographs taken in sunny weather may fail when it is used at night, even if the objects have not changed. This difference between training and test data is commonly called a domain shift. Domain adaptation addresses the problem by using at least some information from the target domain, such as unlabeled night-time images. Domain generalization is more demanding because the target domain is completely unseen during training. It tries to learn features that remain useful across several source domains or to create artificial variations that imitate future changes. Neither setting guarantees success in the real world, where weather, cameras, and user behavior may change together. Researchers must therefore report clearly what target information their methods use.

## 参考翻译

一个在晴天照片上训练的模型，即使物体本身没有改变，在夜间使用时也可能失效。训练数据和测试数据之间的这种差异通常称为领域偏移。领域适应会利用至少一部分目标域信息，例如没有标签的夜间图像。领域泛化要求更高，因为训练过程中完全看不到目标域。它通常学习能够跨多个源域保持有效的特征，或者人工生成变化来模拟未来环境。现实中天气、相机和用户行为可能同时改变，因此两种设定都无法保证成功。研究者必须明确说明方法到底使用了哪些目标域信息。

## 抓词与长句

- domain shift 领域偏移；target domain 目标域；unlabeled 无标签的；artificial variation 人工变化。
- 核心区别：adaptation 看得到目标域信息，generalization 看不到目标域。
