# 小样本学习

类型：同难度模拟。根据常见计算机英语题材自编的模拟练习，没有原题命中的含义。

涉及公司政策、产业趋势的内容按原练习的历史背景阅读，不作为当前新闻。

## English

> Deep learning systems often require thousands of labeled examples, whereas humans can recognize a new object after seeing it only a few times. Few-shot learning attempts to reduce this gap by training models that can adapt to new classes with limited data. One approach learns a representation in which similar examples are placed close together, allowing a new sample to be classified by comparison. Another approach, called meta-learning, trains the model across many small tasks so that it learns how to adapt quickly. Although these methods perform well on carefully designed benchmarks, their accuracy may drop when test images come from a different domain. Building models that remain reliable under such changes is still an open problem.

## 参考翻译

深度学习系统通常需要数千个带标注样本，而人类只看几次就能识别一个新物体。小样本学习试图缩小这一差距，使模型能够利用少量数据适应新的类别。一种方法学习合适的表示，使相似样本在表示空间中彼此接近，从而通过比较完成新样本分类。另一种称为元学习的方法让模型在大量小任务上训练，以学习如何快速适应。虽然这些方法在精心设计的基准测试中表现良好，但当测试图像来自不同领域时，准确率可能明显下降。如何使模型在这种变化下仍然可靠，仍是开放问题。

## 抓词与长句

- labeled example 标注样本；representation 表示；meta-learning 元学习；benchmark 基准测试。
- `whereas` 表示对比；`in which...` 修饰 representation。
