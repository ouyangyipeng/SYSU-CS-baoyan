# 工具调用智能体

类型：同难度模拟。根据常见计算机英语题材自编的模拟练习，没有原题命中的含义。

涉及公司政策、产业趋势的内容按原练习的历史背景阅读，不作为当前新闻。

## English

> A language model can answer questions from its internal knowledge, but an agent can also use tools to obtain current information or change the external world. It may search a database, run code, or send a request to another service. Tool use extends the model’s capabilities, yet it also makes errors more costly because an incorrect decision may trigger a real action. Reliable agents need to select suitable tools, provide valid arguments, check returned results, and recover when a call fails. Designers also need traces that explain what the agent observed and why it acted. Without such controls, a system may appear successful in a short demonstration while remaining unreliable in everyday use.

## 参考翻译

语言模型可以依靠内部知识回答问题，而智能体还能够使用工具获取最新信息或改变外部世界，例如查询数据库、运行代码或向其他服务发送请求。工具扩展了模型能力，也使错误代价更高，因为一次错误决策可能触发现实操作。可靠的智能体需要选择合适工具、填写有效参数、检查返回结果，并在调用失败时恢复。设计者还需要保留执行轨迹，说明智能体观察到了什么以及为何采取某个动作。缺少这些控制时，系统可能在短暂演示中看似成功，却无法在日常使用中保持可靠。

## 抓词与长句

- internal knowledge 内部知识；argument 参数；recover 恢复；trace 执行轨迹；demonstration 演示。
- `what... and why...` 是 explain 后的两个并列宾语从句。
