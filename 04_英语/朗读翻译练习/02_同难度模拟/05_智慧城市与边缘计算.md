# 智慧城市与边缘计算

## English

> Smart-city applications use cameras and sensors to monitor traffic, air quality, and public facilities. Sending every piece of data to a distant cloud can simplify management, but it may also create long delays and consume substantial network bandwidth. Edge computing moves part of the computation closer to where the data is produced. A roadside device, for example, can detect an accident locally and send only the result to the cloud. This design improves response time and may reduce the exposure of private data. However, edge devices have limited power, memory, and computing capacity, and they are harder to maintain than centralized servers. A practical system must decide which tasks should run locally and which should remain in the cloud.

## 参考翻译

智慧城市应用利用摄像头和传感器监测交通、空气质量与公共设施。把所有数据都发送到远端云端虽然便于集中管理，却可能带来较长延迟并消耗大量网络带宽。边缘计算把一部分计算移动到数据产生的位置附近。例如，路侧设备可以在本地检测事故，只把结果发送到云端。这种设计既能缩短响应时间，也可能减少隐私数据的暴露。不过，边缘设备的电力、内存和算力有限，而且比集中式服务器更难维护。实际系统必须决定哪些任务在本地执行，哪些任务仍留在云端。
