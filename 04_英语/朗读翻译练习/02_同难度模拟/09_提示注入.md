# 提示注入

类型：同难度模拟。根据常见计算机英语题材自编的模拟练习，没有原题命中的含义。

涉及公司政策、产业趋势的内容按原练习的历史背景阅读，不作为当前新闻。

## English

> Large language model agents can search the web, read documents, and call external tools, which makes them more useful than isolated chatbots. The same abilities also create new security risks. A malicious instruction hidden in a webpage may persuade an agent to ignore the user’s goal, reveal private context, or invoke a tool without proper permission. This attack is known as prompt injection. Simply telling the model to reject harmful instructions is not sufficient, because untrusted content and trusted commands are processed in the same language. Safer systems separate data from instructions, restrict tool permissions, and record actions for later review. Even with these defenses, human confirmation may still be necessary before an agent performs an irreversible operation.

## 参考翻译

大语言模型智能体能够搜索网页、读取文档并调用外部工具，因此比孤立的聊天机器人更有用，但这些能力也带来了新的安全风险。网页中隐藏的恶意指令可能诱导智能体忽略用户目标、泄露私有上下文，或者在没有适当权限的情况下调用工具，这类攻击称为提示注入。仅仅要求模型拒绝有害指令并不足够，因为不可信内容和可信命令都以同一种自然语言被处理。更安全的系统会区分数据和指令、限制工具权限，并记录操作以便审查。即便采取这些防护，在执行不可逆操作前仍可能需要人工确认。

## 抓词与长句

- isolated chatbot 孤立聊天机器人；malicious 恶意的；prompt injection 提示注入；irreversible 不可逆的。
- `which` 指代前面整组工具能力，不只是最后一个动作。
