# 虚拟内存与大模型

类型：同难度模拟。根据常见计算机英语题材自编的模拟练习，没有原题命中的含义。

涉及公司政策、产业趋势的内容按原练习的历史背景阅读，不作为当前新闻。

## English

> Modern models can be larger than the physical memory available on a personal device. Virtual memory allows a program to use a large address space by moving pages between memory and storage when needed. This mechanism makes execution possible, but frequent page faults can make it extremely slow because storage is much slower than memory. For models in which only part of the parameters is used at each step, the system can improve performance by keeping frequently used data in memory and prefetching likely-needed pages. Incorrect predictions, however, waste bandwidth and may remove useful data too early. Efficient execution therefore requires cooperation between the model’s access pattern and the operating system’s memory manager.

## 参考翻译

现代模型的规模可能超过个人设备可用的物理内存。虚拟内存通过在需要时在内存和存储之间移动页面，使程序能够使用较大的地址空间。这一机制让程序可以运行，但频繁缺页会使速度大幅下降，因为存储远慢于内存。对于每一步只使用部分参数的模型，系统可以把常用数据留在内存中，并预取可能即将需要的页面来提高性能。不过，预测错误会浪费带宽，也可能过早移除有用数据。因此，高效执行需要模型访问模式与操作系统内存管理器相互配合。

## 抓词与长句

- physical memory 物理内存；address space 地址空间；page fault 缺页；prefetch 预取；access pattern 访问模式。
- 注意区分内存、存储与地址空间，不必把通识说明翻译成具体系统实现。
