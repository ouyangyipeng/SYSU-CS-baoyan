# 云计算

类型：扩展题材。根据常见计算机英语题材自编的模拟练习，没有原题命中的含义。

## English

> Cloud computing allows users to obtain computing power, storage, and software services over a network instead of owning all the hardware themselves. A company can rent virtual machines when demand rises and release them when the workload falls, paying only for the resources it uses. Large providers operate data centers in several regions so that services can remain available even when one machine or location fails. Cloud platforms make deployment faster, but they also introduce dependence on network connections and external providers. Users must decide how to protect data, control access, and avoid unexpected costs. For applications with strict latency or privacy requirements, part of the work may still need to run on local or edge devices.

## 参考翻译

云计算使用户能够通过网络获得算力、存储和软件服务，而不必自己拥有全部硬件。企业可以在需求上升时租用虚拟机，在负载下降后释放资源，并按照实际使用量付费。大型云服务商会在多个地区运营数据中心，使服务在一台机器或一个地点故障时仍能继续运行。云平台能加快部署，但也会让系统依赖网络连接和外部服务商。用户还需要考虑数据保护、访问控制和意外成本。对延迟或隐私要求严格的应用，部分工作仍可能需要在本地或边缘设备上运行。
