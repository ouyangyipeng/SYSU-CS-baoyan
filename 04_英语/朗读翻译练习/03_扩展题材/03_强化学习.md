# 强化学习

## English

> Reinforcement learning trains an agent to make decisions through interaction with an environment. At each step, the agent observes the current state, chooses an action, and receives a reward that indicates how useful the action was. The goal is not simply to maximize the immediate reward but to learn a policy that produces high total rewards over time. This method has been applied to games, robotics, resource management, and the alignment of language models. A major challenge is exploration, because the agent must try unfamiliar actions without wasting too much time on poor choices. Another risk is that an imperfect reward function may encourage behavior that scores well but does not match the designer’s true intention.

## 参考翻译

强化学习通过让智能体与环境交互来学习决策。在每一步中，智能体观察当前状态、选择动作，并收到一个表示该动作效果的奖励。其目标并不是只让当前奖励最大，而是学习一套能够长期获得较高累计奖励的策略。这种方法已用于游戏、机器人、资源管理和语言模型对齐。强化学习的一项主要困难是探索：智能体需要尝试陌生动作，又不能在效果很差的选择上浪费过多时间。另一个风险是奖励函数设计不完善，导致智能体获得高分，却没有实现设计者真正想要的行为。
