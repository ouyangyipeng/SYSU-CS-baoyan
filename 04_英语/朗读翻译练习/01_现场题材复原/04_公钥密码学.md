# 公钥密码学

## English

> Cryptography protects information by transforming readable data into a form that unauthorized users cannot understand. In symmetric encryption, the same secret key is used to encrypt and decrypt a message, which is efficient but requires the key to be shared safely. Public-key cryptography instead uses a pair of related keys: one can be shared publicly, while the other must remain private. A sender can encrypt data with the public key so that only the holder of the private key can recover it. Digital signatures use the pair in another way to verify who created a message and whether it was changed. In practice, secure Internet connections often combine public-key methods for key exchange with faster symmetric encryption for the actual data.

## 参考翻译

密码学通过把可读数据转换为未授权用户无法理解的形式来保护信息。对称加密使用同一个密钥加密和解密，效率较高，但需要安全地共享密钥。公钥密码学则使用一对相关密钥：其中一个可以公开，另一个必须保密。发送方可用公钥加密数据，只有持有私钥的人才能恢复数据。数字签名以另一种方式使用这对密钥，用于验证消息发送者以及内容是否被修改。实际的安全互联网连接通常使用公钥方法完成密钥交换，再用更快的对称加密传输数据。
